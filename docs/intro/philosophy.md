# 설계 철학: 네 대가와 정밀 계산

## 네 명의 투자 대가는 누구인가요?

| 인물 | 어떤 사람인가요? | 이 프레임워크에서 맡은 역할 |
|---|---|---|
| **돤융핑(段永平)** | 샤오바왕·BBK를 세우고 OPPO·vivo의 뿌리를 만든 중국의 기업가 겸 투자자. 넷이즈·애플·마오타이 장기 투자로 유명해요 | **"옳은 사업인가?"** 사업 모델의 본질. 나머지 세 관점의 공통 출발점이에요 |
| **워런 버핏** | 버크셔 해서웨이 회장 | 해자, 안전마진, 경영진, 재무·가치평가 |
| **찰리 멍거** | 버핏의 평생 파트너 | 역발상("어떻게 망할까?"), 리스크 목록, 심리적 편향 점검 |
| **리루(李录)** | 히말라야 캐피털 창업자. 멍거가 자기 돈을 맡긴 투자자로 알려져 있어요 | 문명의 흐름, 패러다임 전환, 산업 가치, 10년 뒤의 확실성 |

## 네 관점을 합치는 방식

**돤융핑 · "옳은 사업"** — 사업 모델의 본질이 나머지 세 관점의 공통 출발점이에요.

| 버핏 | 멍거 | 리루 |
|:---:|:---:|:---:|
| 해자<br>안전마진<br>경영진 | 역발상<br>리스크 목록<br>편향 자가 점검 | 문명 추세<br>패러다임 전환<br>산업 가치 |

네 대가는 단순히 일을 나눠 맡는 게 아니라 **서로 도전하도록** 설계되어 있어요.

- 돤융핑이 "좋은 사업"이라고 하면, 멍거는 "어떻게 망할 수 있지?"라고 물어요.
- 버핏이 "충분히 싸다"고 하면, 리루는 "10년 뒤에도 살아 있을까?"라고 물어요.

그래서 결과물은 보고서 네 개를 이어 붙인 게 아니라 **네 가지 사고방식이 부딪친 결과**예요.

::: tip 참고
보고서에 나오는 "버핏은 이렇게 말했다" 같은 대가의 논평은 AI가 각 대가의 투자 철학과 말투를 흉내 낸 **모의 논평**이에요. 대가 본인이 해당 종목에 대해 한 말이 아니에요.
:::

## 리서치 원칙 (모든 스킬에 공통으로 적용)

원본 저장소의 프로젝트 규칙(`CLAUDE.md`)에는 모든 스킬이 지켜야 할 최우선 원칙이 적혀 있어요.

- **객관, 객관, 객관** — 모든 분석은 사실과 데이터에 근거하고, 주관적 억측을 금지해요.
- **사실과 의견을 엄격히 구분** — 사실은 데이터로 뒷받침하고, 의견은 반드시 '의견' 또는 '추측'으로 표시해요.
- **입장을 미리 정하지 않기** — 강세도 약세도 전제하지 않고, 데이터 → 논리 → 결론 순서로 가요.
- **주관적 표현 금지** — "내 생각에는", "분명히" 대신 "데이터에 따르면", "근거에 따르면"을 써요.
- **양면 제시** — 핵심 판단마다 반대 논거("하지만 다른 한편으로는…")를 붙여요.
- **모르면 모른다고** — 불확실한 것은 "불확실" 또는 "데이터 부족"이라고 솔직히 적어요.

보고서 작성 규칙도 있어요.

- 문체는 직설적이고 날카롭게, 군더더기 없이 써요.
- 데이터에는 출처를 달고, 핵심 데이터는 최소 두 개 출처로 교차 검증해요.
- 추정치에는 반드시 '추정'이라고 적어요.
- 점수는 ★ 1~5개로 매기고, 반 개짜리 별은 쓰지 않아요.

## 금융 엄밀성 도구

`tools/financial_rigor.py`는 AI의 암산을 대신하는 계산 도구예요. 스킬 지시서 곳곳에서 "반드시 이 도구로 계산하라"고 요구해요.

| 기능 | 명령 | 해결하는 문제 |
|------|------|-----------|
| **시가총액 검산** | `verify-market-cap` | 주가 × 총 발행주식 수를 정밀 계산해 단위 오류를 잡아요 |
| **밸류에이션 검산** | `verify-valuation` | PER/PBR/ROE/FCF Yield를 정밀 십진 연산으로 계산해요 |
| **다중 출처 교차 검증** | `cross-validate` | 여러 출처의 같은 데이터를 자동 비교하고, 허용 오차를 넘으면 경고해요 |
| **3가지 시나리오 가치평가** | `three-scenario` | 낙관/중립/비관 시나리오의 목표가를 정밀 계산해요 |
| **벤포드 법칙 검사** | `benford` | 재무 데이터 첫 자리 숫자의 분포 이상(조작 의심 신호)을 찾아요 |
| **정밀 계산기** | `calc` | 어떤 재무 수식이든 정밀하게 계산해 LLM 암산을 대체해요 |

**설계 원칙:** 모든 계산은 부동소수점(`float`) 근사가 아니라 파이썬 `decimal.Decimal`(정밀 십진 연산)을 써요. 금융에서는 `0.1 + 0.2 = 0.3`이 틀리면 안 되니까요.
