# 전체 구조

AI Berkshire는 **세 개의 층**으로 이루어져 있어요.

```
┌──────────────────────────────────────────────────┐
│ ① 스킬 층 — "무엇을 할까?"                         │
│    상황별 명령어 21개 (예: /investment-team 텐센트)  │
├──────────────────────────────────────────────────┤
│ ② 멀티 에이전트 층 — 팀 리더 + 네 대가 에이전트       │
│    각자 검색하고 판단한 뒤 서로 반박, 팀 리더가 종합   │
├──────────────────────────────────────────────────┤
│ ③ 도구·데이터 층 — 정밀 계산, 실시간 검색, 표본 검수  │
│    financial_rigor.py · report_audit.py 등        │
└──────────────────────────────────────────────────┘
```

| 층 | 하는 일 |
|---|---|
| **① 스킬 층** | "무엇을 할지"를 명확한 입구로 나눴어요. 심층 리서치, 실적 분석, 산업 선별, 보유 종목 관리, 사고 도구 중 상황에 맞게 골라요. |
| **② 에이전트 층** | 팀형 스킬(`/investment-team`, `/earnings-team` 등)에서는 팀 리더가 네 대가 관점의 에이전트 4개를 병렬로 돌려요. 각자 독립적으로 검색·판단하고 서로 반박한 뒤 종합해요. 가벼운 스킬은 이 층을 건너뛰고 바로 도구를 써요. |
| **③ 도구 층** | 정밀 계산, 실시간 검색, 보고서 표본 검수로 모든 보고서의 데이터 엄밀성을 검증할 수 있게 해요. |

## 팀 리더가 네 대가 에이전트를 병렬로 돌리는 방식

![팀 리더가 네 대가 에이전트를 병렬 조율하는 그림](/images/team-core-en.svg)

`/investment-team`을 예로 들면 역할은 이렇게 나뉘어요.

| 역할 | 담당 | 관점 |
|---|---|---|
| 팀 리더(메인 AI) | 전체 조율, 종합 판단, 최종 보고서 | 네 대가 종합 |
| business-analyst | 사업 모델과 해자 | 돤융핑 |
| financial-analyst | 재무제표와 가치평가 | 버핏 |
| industry-researcher | 산업 구도와 경쟁 | 멍거 |
| risk-assessor | 리스크와 경영진 | 리루 |

자세한 절차는 [`/investment-team` 스킬 페이지](/skills/investment-team)에서 볼 수 있어요.

## 원본 저장소의 폴더 구성

| 폴더 | 내용 |
|---|---|
| `skills/` | Claude Code용 스킬 지시서 원본 (`.md`) — 이 사이트가 번역한 대상이에요 |
| `codex-skills/` | 같은 내용을 Codex용 스킬 패키지로 자동 변환한 것 |
| `codex-prompts/` | Codex 슬래시 프롬프트 호환 버전 |
| `tools/` | 파이썬 계산·데이터 도구 |
| `scripts/` | 설치 스크립트 (macOS/Linux/Windows) |
| `reports/` | 이 프레임워크로 만든 리서치 보고서 (이 사이트의 다음 단계 범위) |
| `data/`, `docs/`, `assets/` | 데이터 파일, 문서, 이미지 |
