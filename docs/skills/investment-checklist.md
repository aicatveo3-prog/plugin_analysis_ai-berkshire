# `/investment-checklist` · 버핏식 매수 전 체크리스트

> 📄 원문: [skills/investment-checklist.md](https://github.com/xbtlin/ai-berkshire/blob/main/skills/investment-checklist.md) · 원문은 중국어이며, 아래는 한국어 번역입니다.

::: tip 한눈에 보기
- **무엇을 하나요?** 사려는 회사를 능력범위 → 좋은 사업 → 해자 → 경영진 → 안전마진 → 비중·결정 규율의 6개 관문에 차례로 통과시키고, 거울 테스트와 즉시 탈락 목록으로 마지막 점검을 해요.
- **언제 쓰나요?** 매수 버튼을 누르기 직전, "정말 사도 되는지" 냉정하게 확인하고 싶을 때 써요. 여러 종목을 한 번에 비교할 때도 좋아요.
- **사용 예:** `/investment-checklist 텐센트, 마오타이, 엔비디아` 또는 `/investment-checklist NVDA AAPL MSFT`
- **결과물:** 회사별 6관문 점수표·핵심 데이터·거울 테스트·결론이 담긴 보고서가 홈 디렉터리의 `~/巴菲特Checklist-….md` 파일로 저장돼요.
- **핵심 특징:** 종목마다 백그라운드 Agent로 데이터를 병렬 수집하고, 밸류에이션은 도구로 정확히 계산하며, AI 정보 풍부도(A/B/C)를 표시해 '자료 부족'과 '탈락'을 구분해요.
:::

## 번역 전문

**원제:** 버핏식 가치투자 매수 전 Checklist

$ARGUMENTS 에 대해 버핏식 가치투자 매수 전 Checklist 분석을 수행합니다.

**지원 입력 형식**: 회사 하나 또는 여러 개를 쉼표/모점(、)/공백으로 구분합니다. 예: `텐센트, 마오타이, 엔비디아` 또는 `NVDA AAPL MSFT`

## 실행 절차

### 1단계: 입력을 해석하여 분석할 모든 회사 식별

$ARGUMENTS 에서 모든 회사명/종목 코드를 해석해 냅니다. 각 회사에 대해 다음을 확정합니다.
- 회사 정식 명칭, 종목 코드, 상장 거래소
- 회사가 비상장이면 '비상장'으로 표시하고 간단한 설명(간접 투자 경로가 있는지)을 제시한 뒤, 전체 Checklist는 건너뜁니다.

### 1.5단계: AI 리서치 편향 사전 경고

각 회사에 대해 '정보 풍부도'를 빠르게 등급(A/B/C)으로 매기고, 보고서에 표시합니다.

| 등급 | 판단 기준 | Checklist에 미치는 영향 |
|------|---------|-----------------|
| A등급 | 상장한 지 오래되었고 데이터가 풍부함 | 정상적으로 수행하되, '컨센서스 함정'을 경계할 것 — 모든 지표가 선명해 보인다고 해서 정말 확실하다는 뜻은 아님 |
| B등급 | 데이터가 제한적이어서 추정이 필요함 | 추정한 지표마다 신뢰도를 표시하고, '좋은 사업' 판단 시 데이터 신뢰성에 가중치를 두어 고려할 것 |
| C등급 | 정보가 극도로 부족함 | 6관문 표를 억지로 채우지 말고, '데이터 부족으로 판단 불가'라고 정직하게 표시하며, 검증 가능한 핵심 질문에 집중할 것 |

**핵심 원칙**: Checklist의 목표는 **나쁜 선택을 배제하는 것**입니다. C등급 회사의 경우 '데이터 부족'은 '불통과'와 같지 않고, '통과'와도 같지 않습니다 — AI가 표를 다 채우지 못했다고 탈락으로 판정할 것이 아니라, '회색지대, 1차 정보 보완 필요'로 정직하게 표시해야 합니다.

돤융핑은 이렇게 말했습니다. "이해가 안 된다"에는 두 가지가 있다 — 하나는 사업이 너무 복잡해서 정말 이해할 수 없는 것이고, 다른 하나는 아직 시간을 들여 들여다보지 않은 것이다. AI 리서치의 한계는 '자료가 적다'와 '이해할 수 없다'를 혼동하기 쉽다는 점입니다.

### 2단계: 병렬 데이터 수집

Task 도구로 **회사마다** 독립된 백그라운드 Agent를 실행해 데이터를 수집합니다(모든 회사를 동시에 병렬로 실행). 각 Agent는 다음을 수집합니다.

1. **수익성**: ROE(5-10년 추세), 매출총이익률, 순이익률, 잉여현금흐름(FCF)
2. **밸류에이션 데이터**: 현재 주가, 시가총액, PER(TTM), 선행 PER, PBR, 배당수익률
3. **성장 추세**: 최근 3년 매출/이익 성장률
4. **재무 건전성**: 부채 수준, 설비투자(CAPEX) 수요, 현금 보유액, 순현금/순부채
5. **경쟁 구도**: 시장 점유율, 주요 경쟁사, 점유율 변화 추세
6. **해자 증거**: 브랜드/전환 비용/네트워크 효과/규모의 경제/기술 장벽에 대한 구체적 증거
7. **경영진 기록**: CEO 이력, 주요 의사결정, 지분 보유, 자본 배분 기록
8. **최신 동향**: 최근 6개월간의 중대 사건(실적, 인수합병, 규제, 경영진 변동 등)

### 3단계: 회사별로 6관문 Checklist 수행

상장된 각 회사에 대해 6개 관문을 차례로 통과시킵니다.

---

#### 제1관: 나는 이 사업을 이해할 수 있는가(능력범위)

반드시 답해야 할 질문:
- [ ] 이 회사가 무엇으로 돈을 버는지 한 문장으로 명확히 말할 수 있는가?
- [ ] 10년 뒤에도 높은 확률로 어떤 사업을 하고 있을까?
- [ ] 성패를 좌우하는 핵심 변수는 무엇인가?
- [ ] 이 산업에 대한 이해가 깊이 있는 연구에서 나온 것인가, 주워들은 이야기에서 나온 것인가?

**채점 기준**(★1-5):
- ★★★★★: 비즈니스 모델이 극도로 단순명료하고, 10년 확실성이 높음(예: 마오타이 — 술을 빚어 술을 판다)
- ★★★★☆: 모델은 명확하지만 기술적 문턱이 있어 이해하려면 어느 정도 전문 지식이 필요함
- ★★★☆☆: 모델은 이해할 수 있으나 10년 확실성이 높지 않고, 산업 변화가 빠름
- ★★☆☆☆: 사업 부문이 복잡하거나 산업이 격변 중이어서 미래를 예측하기 어려움
- ★☆☆☆☆: 완전히 능력범위 밖

**강제 탈락**: 돈을 버는 방식조차 명확히 설명하지 못하면, 바로 '능력범위 밖, 분석하지 않음'으로 표시합니다.

---

#### 제2관: 이것은 좋은 사업인가(경제적 특성)

데이터로 말하며, **핵심 지표는 반드시 도구로 정확히 계산합니다**:

```bash
python3 tools/financial_rigor.py verify-valuation \
  --price {주가} --eps {EPS} --bvps {주당순자산} --fcf-per-share {주당FCF} --dividend {주당배당금}
```

| 지표 | 해당 회사 수치 | 참고 기준 | 판단 |
|------|-----------|---------|------|
| ROE(5년 평균) | | >15% 우수, >20% 탁월 | |
| 매출총이익률 | | >40%면 가격 결정력 시사 | |
| 잉여현금흐름(FCF) | | 지속적으로 플러스, ≈순이익 | |
| 설비투자 강도 | | 자산 경량형이 자산 중량형보다 우수 | |
| 부채 수준 | | 이자부 부채/순이익 < 3년 | |

**채점 기준**(★1-5):
- ★★★★★: ROE>25%, 높은 매출총이익률, 강한 FCF, 자산 경량형, 낮은 부채(전부 충족)
- ★★★★☆: 4개 항목 충족
- ★★★☆☆: 3개 항목 충족
- ★★☆☆☆: 2개 항목 충족 또는 추세 악화
- ★☆☆☆☆: 대부분 미충족 또는 FCF가 지속적으로 마이너스

항목별로 점검합니다.

| 해자 유형 | 보유 여부 | 구체적 증거 | 넓어지는가, 좁아지는가? |
|-----------|---------|---------|--------------|
| 브랜드/가격 결정력 | | | |
| 전환 비용 | | | |
| 네트워크 효과 | | | |
| 원가/규모 우위 | | | |
| 기술/특허 장벽 | | | |

추가 검증: 경쟁사에게 100억을 준다면 이 사업을 복제할 수 있을까?

**채점 기준**(★1-5):
- ★★★★★: 여러 겹의 해자가 겹쳐 있고 넓어지는 중
- ★★★★☆: 최소 하나의 강한 해자가 있고 안정적
- ★★★☆☆: 해자는 있지만 충분히 깊지 않거나, 추세가 불분명
- ★★☆☆☆: 해자가 잠식되고 있음
- ★☆☆☆☆: 뚜렷한 해자 없음

#### 제4관: 경영진은 신뢰할 만한가(사람 요인)

| 점검 항목 | 평가 |
|--------|------|
| 정직성(약속 vs 이행) | |
| 자본 배분 능력(자사주 매입/배당/인수합병 기록) | |
| 주주 이익 지향(지분 보유, 보수) | |
| 오너 마인드(창업자 vs 전문 경영인) | |
| 기업 지배구조(특수관계자 거래, 영업권, 감사) | |
| CEO가 떠나도 정상적으로 돌아가는가? | |

**채점 기준**(★1-5):
- ★★★★★: 창업자가 이끌고, 자본 배분이 탁월하며, 이해관계가 완전히 일치
- ★★★★☆: 경영진이 우수하지만 작은 흠이 있음
- ★★★☆☆: 경영진은 합격점이지만 지배구조상 우려가 있음
- ★★☆☆☆: 신뢰성 또는 지배구조 문제가 있음
- ★☆☆☆☆: 심각한 신뢰성 문제(→ 강제 탈락)

#### 제5관: 가격은 충분히 싼가(안전마진)

| 지표 | 수치 | 역사적 분위 | 판단 |
|------|------|---------|------|
| PER (TTM) | | | |
| 선행 PER | | | |
| PBR | | | |
| 배당수익률 | | | |
| FCF Yield | | | |

추가 검증(**반드시 도구로 정확히 계산하고, 암산은 금지합니다**):
```bash
python3 tools/financial_rigor.py three-scenario \
  --price {주가} --eps {EPS} --shares {발행주식수_억주} \
  --growth {낙관} {중립} {비관} --pe {낙관PER} {중립PER} {비관PER} --currency {통화}
```
- 세 가지 시나리오에서의 밸류에이션 구간(도구 출력 결과를 사용)
- 판단이 틀렸다면, 현재 가격에 매수했을 때 최대 얼마까지 잃을 수 있는가?
- 주가가 반토막 나도 추가 매수할 용기가 있는가?

**채점 기준**(★1-5):
- ★★★★★: 내재가치 대비 50% 이하 가격, 극단적인 안전마진
- ★★★★☆: 내재가치 대비 70% 수준 가격, 양호한 안전마진
- ★★★☆☆: 적정 밸류에이션, 안전마진은 보통
- ★★☆☆☆: 다소 비쌈, 안전마진 부족
- ★☆☆☆☆: 심각한 고평가

#### 제6관: 비중과 의사결정 규율(감정 폭주 방지)

다음 감정 신호를 점검합니다.
- FOMO 때문에 사고 싶은 것은 아닌가?
- 남이 추천해서 사고 싶은 것은 아닌가?
- 5년간 거래 정지되어도 받아들일 수 있는가?
- 매수 논리를 200자 이내로 명확히 쓸 수 있는가?

### 4단계: 거울 테스트

각 회사에 대해 거울 테스트 문장을 작성합니다.

> "나는 ___원에 ___회사를 매수한다. 왜냐하면:
> 1. 이 사업의 본질은 ___이며, 나는 그것을 이해한다;
> 2. 이 회사의 해자는 ___이며, 넓어지고/좁아지고 있다;
> 3. 경영진은 ___하며, 신뢰할 만하다/신뢰할 만하지 않다;
> 4. 현재 가격은 내재가치의 ___% 수준이며, 충분한 안전마진이 있다/없다;
> 5. 설령 내가 틀리더라도 하방 위험은 통제 가능하다/불가능하다. 왜냐하면 ___."

(역주: 첫 줄의 '원'은 원문의 통화 단위 표현을 옮긴 것으로, 해당 종목의 거래 통화로 읽으면 됩니다. 4번은 원문의 '몇 할' 표현을 %로 옮겼습니다.)

**5개 문장을 완성하지 못하면 = 사지 않습니다.** '통과' 또는 '불통과'를 명확히 표시합니다.

---

### 5단계: 즉시 탈락 목록

각 회사를 항목별로 점검하여, 하나라도 해당되면 바로 '탈락'으로 표시합니다.

- [ ] 이 회사가 어떻게 돈을 버는지 명확히 말할 수 없음
- [ ] 3년 연속 잉여현금흐름이 마이너스이고 개선 조짐이 보이지 않음
- [ ] 경영진에게 신뢰성 오점이 있음
- [ ] 경쟁 우위가 되돌릴 수 없게 잠식되고 있음
- [ ] '다음 매수자가 더 높은 가격을 내 주기를' 기대해야 돈을 벌 수 있음(바보 게임)
- [ ] 이 투자가 0이 되는 결과를 감당할 수 없음
- [ ] 매수 이유가 주로 '다들 사고 있어서' 또는 '최근에 많이 올라서'임
- [ ] 매수 이유를 200자 이내로 명확히 쓸 수 없음

### 7단계: 최종 결론과 파일 저장

각 회사에 대해 명확한 결론을 제시합니다(회피하지 않음).
- ✅ **Checklist 통과**(X/6관문) — 심층 리서치 단계로 넘어갈 수 있음
- ❌ **Checklist 불통과** — 어떤 레드라인이 발동되었는지 설명

## 출력 형식 요구사항

1. 각 회사는 독립된 장으로 구성하며, 6관문 점수표 + 핵심 데이터표 + 주요 리스크(3-5개) + 거울 테스트 + 명확한 결론을 포함할 것
2. 여러 회사일 경우 마지막에 종합 비교표를 첨부할 것
3. 모든 점수는 ★ 기호(★1-5)를 사용하며, 반 개짜리 별은 쓰지 말 것
4. 데이터에는 반드시 출처 시점을 표시하고, 추정치에는 반드시 '추정'이라고 명시할 것
5. 글 끝에 맺음말을 붙이고, 버핏의 명언 "투자의 제1원칙은 돈을 잃지 않는 것이다"와 호응하게 할 것
6. 문체: 직설적이고 날카롭게, 군더더기 없이. 버핏/멍거/돤융핑의 어록을 곳곳에 섞어 코멘트할 것

## 핵심 원칙

- **놓칠지언정 틀리지 않는다**: Checklist의 목표는 나쁜 선택을 배제하는 것이지, 최고의 선택을 찾는 것이 아닙니다.
- **능력범위를 정직하게 마주한다**: 모르면 모른다고 말하고, 억지로 분석하지 않습니다.
- **안전마진은 생명선이다**: 좋은 회사라도 비싸게 사면 돈을 잃습니다.
- **거울 테스트는 건너뛸 수 없다**: 이유를 명확히 말하지 못하면 사지 않습니다. 예외는 없습니다.
