> 📄 원문: [skills/portfolio-review.md](https://github.com/xbtlin/ai-berkshire/blob/main/skills/portfolio-review.md) · 원문은 중국어이며, 아래는 한국어 번역입니다.

::: tip 한눈에 보기

- **핵심 특징:** 모든 돈에 기회비용이 있다는 버핏식 사고, 종목 간 숨은 상관관계 점검, 4가지 스트레스 테스트, "가장 먼저 해야 할 한 가지"를 반드시 결론으로 내는 점이 특징이에요.

## 번역 전문

**원제:** 포트폴리오 관리: "회사 연구"에서 "포트폴리오 관리"로

$ARGUMENTS 에 대해 투자 포트폴리오 점검과 최적화를 수행합니다.

**지원하는 입력 형식**:
- 보유 종목 목록, 예: `텐센트30%, 메이퇀20%, 마오타이20%, 엔비디아15%, 현금15%`
- 또는: `텐센트 500주 @480홍콩달러, 메이퇀 1000주 @130홍콩달러, ...`
- 또는: `내 보유 종목` (저장된 포트폴리오 파일 `reports/portfolio-latest.md`가 이미 있는 경우)

> "분산 투자는 무지에 대한 보호책입니다. 자기가 무엇을 하는지 아는 사람에게 분산 투자는 별 의미가 없습니다." —— 버핏
>
> "제가 평생 본 정말 좋은 투자 기회는 열 손가락으로 다 셀 수 있을 정도입니다." —— 리루

## 설계 철학

회사를 연구하는 것은 투자의 절반에 불과합니다. 나머지 절반은 **포트폴리오 차원의 의사결정**입니다:
- 얼마나 살 것인가? (비중)
- 어떤 돈으로 살 것인가? (자금 출처 — 새 돈인가, 종목 교체인가)
- 기존 보유 종목과 충돌하지 않는가? (상관관계)
- 최적의 포트폴리오는 어떤 모습인가? (기회비용)

버핏은 결코 한 종목을 따로 떼어 보지 않습니다 — 그는 언제나 "이것이 내가 할 수 있는 최선의 선택인가?"를 생각합니다.

## 실행 절차

### 1단계: 보유 종목 파싱

입력에서 현재 보유 종목을 파싱해 아래 형식으로 표준화합니다:

| 종목 | 코드 | 보유 수량 | 매입 단가 | 현재가 | 평가액 | 비중 | 손익 |
|------|------|--------|-------|------|------|------|------|

입력에 금액 없이 비율만 있다면 비율 기준으로 분석하면 됩니다.

동시에 기존 포트폴리오 파일(`reports/portfolio-latest.md`)이 있는지 확인하고, 있으면 읽어서 업데이트합니다.

### 2단계: 최신 데이터 수집

Task 도구로 백그라운드 Agent를 띄워 WebSearch로 각 보유 종목에 대해 병렬로 수집합니다:
1. 현재 주가와 밸류에이션 지표(PER, PBR, 배당수익률)
2. 최근 한 분기의 주요 재무 변화
3. 최근의 중대 이벤트
4. 애널리스트 컨센서스(선행 PER, 목표 주가)

각 보유 종목에 대해 `tools/financial_rigor.py verify-valuation`으로 밸류에이션 데이터를 검증합니다. 각 종목에 정보 풍부도(A/B/C 등급)를 표시하고, C등급 종목의 분석 결론에는 낮은 신뢰도를 표시합니다.

### 3단계: 종목별 건강 검진

각 보유 종목에 대해 빠른 건강 검진을 합니다:

| 종목 | 현재 PER | 매수 논리 변화 여부 | 투자 논리 건강도 | 비중 제안 |
|------|:------:|:--------------:|:---------:|---------|
| 텐센트 | 18x | 변화 없음 | 8/10 | 적정 |
| 메이퇀 | 25x | 경쟁 심화 | 6/10 | 다소 높음, 비중 축소 검토 |

각 보유 종목에 대해 답합니다:
- [ ] **오늘 이 종목을 보유하고 있지 않다면, 현재 가격에 그래도 사겠습니까?**
- [ ] **내일부터 거래할 수 없다면, 5년 동안 보유해도 마음이 편하겠습니까?**
- [ ] **매수 당시의 투자 논리가 아직 온전합니까?**

**돤융핑**: "10년 동안 보유하고 싶지 않은 주식이라면, 단 하루도 보유하지 마십시오."

### 4단계: 포트폴리오 차원 분석

#### 4.1 집중도 분석

| 지표 | 현재 값 | 권장 범위 | 판단 |
|------|-------|---------|------|
| 최대 보유 종목 비중 | | <40% | |
| 상위 3개 종목 비중 | | 50-80% | |
| 총 보유 종목 수 | | 5-15개 | |
| 현금 비중 | | 10-30%(시장 환경에 따라) | |

**리루의 기준**: 핵심 보유 종목 3~5개, 상위 3개가 80% 이상. **단, 이는 모든 종목을 철저히 연구했다는 전제가 필요합니다.**

**버핏의 기준**: 핵심 보유 종목은 10개 이하이되, 위성 비중은 더 많이 허용합니다.

#### 4.2 상관관계 점검

보유 종목 간의 숨은 연관성을 식별합니다:

| 종목A | 종목B | 상관 유형 | 리스크 |
|-------|-------|---------|------|
| 텐센트 | 콰이서우 | 모두 중국 인터넷 | 규제 리스크 동조 |
| 엔비디아 | TSMC | AI 공급망 상·하류 | AI Capex에 따라 같은 방향으로 변동 |
| 메이퇀 | 핀둬둬 | 모두 중국 소비 | 거시 소비에 따라 같은 방향으로 변동 |

**체크리스트**:
- [ ] 비중의 50% 넘게 같은 테마/산업에 노출되어 있지 않습니까?
- [ ] 비중의 50% 넘게 같은 국가/통화에 노출되어 있지 않습니까?
- [ ] 미·중 관계가 악화되면 포트폴리오는 얼마나 손실을 보겠습니까?
- [ ] 글로벌 경기 침체가 오면 포트폴리오는 얼마나 손실을 보겠습니까?

#### 4.3 기회비용 분석

이것이 버핏의 가장 핵심적인 사고방식입니다 — **모든 돈은 수익률이 가장 높은 곳에 있어야 합니다**.

모든 보유 종목을 "기대 연환산 수익률" 순으로 정렬합니다:

| 순위 | 종목 | 현재 비중 | 기대 연환산 수익률 | 확실성 | 기대 수익률×확실성 |
|:----:|------|:-------:|:----------:|:------:|:--------------:|
| 1 | | | | | |
| 2 | | | | | |
| ... | | | | | |

기대 수익률 추정 방법(`tools/financial_rigor.py three-scenario`로 계산):
- **간이 공식**: 기대 연환산 수익률 ≈ FCF Yield + 기대 성장률(주된 방법)
- **가치형 검증**: 안전마진 회귀 + 이익 성장률 + 배당수익률
- **성장형 검증**: 이익 성장률 × 적정 PER의 변화

**핵심 질문**: 순위 맨 아래 종목의 기대 수익률이 현금(무위험 이자율 ~4%)보다 높습니까? 그렇지 않다면 매도해 현금으로 바꿔야 합니다.

#### 4.4 스트레스 테스트

| 시나리오 | 가정 | 포트폴리오 예상 영향 | 최대 낙폭 |
|------|------|-----------|---------|
| 글로벌 경기 침체 | 기업 이익 20-30% 감소 | | |
| 미·중 갈등 격화 | 중국 기업 주식 50% 할인 | | |
| 금리 급등 | 10년물 국채 금리→6% | | |
| 기술주 버블 붕괴 | 기술주 PER 40% 축소 | | |

각 시나리오에 대해 정성적 평가 + 대략적 추정을 합니다(각 보유 종목의 산업 특성과 과거 밸류에이션 변동 범위를 기준으로):
- 어떤 종목이 가장 큰 타격을 받습니까? 대략적인 영향 방향과 규모 범위
- 포트폴리오 전체가 감당할 수 있습니까?
- 헤지가 필요합니까?

### 5단계: 최적화 제안

#### 5.1 리밸런싱 제안

위 분석을 바탕으로 구체적인 리밸런싱 제안을 제시합니다:

| 행동 | 종목 | 현재 비중 | 제안 비중 | 이유 |
|------|------|:-------:|:-------:|------|
| 추가 매수 | | | | |
| 비중 축소 | | | | |
| 전량 매도 | | | | |
| 신규 매수 | | | | |
| 유지 | | | | |

#### 5.2 대체 종목 찾기

포트폴리오에 "현금만 못한" 종목이 있거나 현금 비중이 너무 높다면, 이 스킬 안에서 개별 종목을 직접 추천하지 말고 `/industry-research` 또는 `/investment-checklist`로 관심 있는 산업/회사를 체계적으로 선별하도록 권합니다.

#### 5.3 현금 관리

| 현재 현금 비중 | 권장 현금 비중 | 이유 |
|:----------:|:----------:|------|

**버핏**: 현재 $3,820억(3,820억 달러)의 현금을 보유하고 있으며 총자산의 25%가 넘습니다 — 좋은 기회를 찾지 못할 때는 현금이 최고의 포지션입니다.

### 6단계: 포트폴리오 보고서 출력

#### 보고서 구조

```
1. 포트폴리오 개요(보유 종목 표 + 파이 차트 설명)
2. 종목별 건강 검진(각 보유 종목의 건강 상태)
3. 포트폴리오 분석
   - 집중도: 과도하게 분산/집중되어 있지 않은가?
   - 상관관계: 숨은 연관성과 리스크 동조
   - 기회비용: 순위가 가장 낮은 종목은 보유할 가치가 있는가?
   - 스트레스 테스트: 극단 시나리오에서의 낙폭 추정
4. 리밸런싱 제안(구체적 조치 + 이유)
5. 다음 점검 시기와 주목할 사항
```

#### 결론은 반드시 명확히 답해야 합니다

1. **포트폴리오 전체 건강도**: 우수 / 양호 / 조정 필요 / 문제 심각
2. **가장 먼저 해야 할 한 가지는 무엇입니까?** (X 추가 매수 / Y 비중 축소 / 유지)
3. **현재 가장 큰 리스크는 무엇입니까?**

### 7단계: 포트폴리오 파일 저장

포트폴리오 정보를 `reports/portfolio-latest.md`에 기록하며, 다음을 포함합니다:
- 최신 보유 종목 표
- 이번 점검 날짜와 결론
- 리밸런싱 기록(누적 추가)
- 다음 점검 알림

## 핵심 원칙

- **모든 돈에는 기회비용이 있습니다** — 평범한 주식을 보유하는 대가는 뛰어난 주식을 놓치는 것입니다
- **집중이 위험한 것이 아니라 무지가 위험한 것입니다** — 깊이 이해하는 3종목을 보유하는 것이 어설프게 아는 30종목을 보유하는 것보다 안전합니다
- **현금도 하나의 포지션입니다** — 좋은 기회를 찾지 못할 때 현금을 들고 있는 것은 부끄러운 일이 아닙니다
- **포트폴리오 차원 > 개별 종목 차원** — 좋은 주식도 잘못된 비중에 있으면 발목을 잡습니다
- **정기적으로 점검하되 과도하게 매매하지 마십시오** — 분기에 한 번 점검이면 충분하며, 매일 시세를 들여다보며 비중을 바꾸지 마십시오
