# `/bottleneck-hunter` · 공급망 병목 사냥꾼

> 📄 원문: [skills/bottleneck-hunter.md](https://github.com/xbtlin/ai-berkshire/blob/main/skills/bottleneck-hunter.md) · 원문은 중국어이며, 아래는 한국어 번역입니다.

::: tip 한눈에 보기
- **무엇을 하나요?** AI 인프라 같은 거대 트렌드를 골라 공급망을 물리적 부품·소재·장비 단위까지 쪼갠 뒤, "트렌드가 계속 커지면 어디가 먼저 모자라게 될까?"를 따져 병목 구간과 관련 상장사를 찾아내요.
- **언제 쓰나요?** 이미 가격에 충분히 반영된 1차 수혜주(GPU, HBM 등) 말고, 아직 덜 알려진 2·3차 공급망 수혜주를 발굴하고 싶을 때 써요.
- **사용 예:** `/bottleneck-hunter AI 인프라` 처럼 추적할 트렌드 이름을 넣어 호출해요. (원문에 별도 호출 예시가 없어 원문에 나온 트렌드 예시 "AI 인프라"를 인수로 넣었어요.)
- **결과물:** 트렌드 검증 → 병목 지도 → 종목 선별 → 기회 순위표·한 페이지 요약 → 행동 제안까지 담긴 보고서를 `reports/bottleneck-map/` 폴더에 만들어요. 병목 종합 지도(`master-map.md`)와 관찰 목록(`watchlist.md`)도 계속 갱신해요.
- **핵심 특징:** 병목 판정 6개 기준(S/A/B 등급), 병목 생명주기 5단계 추적, 가치투자 필터를 통한 투기 배제, 결론마다 두 개 이상 출처로 교차 검증해요.

## 번역 전문

**원제:** 공급망 병목 사냥꾼: AI 기반 글로벌 산업 사슬 병목 차익거래

$ARGUMENTS 거대 트렌드(슈퍼 트렌드)에 대해 공급망 병목 스캔과 차익거래 기회 발굴을 수행합니다.

## 핵심 이념

"AI가 어떤 주식을 추천하나"를 묻지 말고, "이 트렌드가 계속 확장된다면 어느 고리가 가장 먼저 모자라게 될까?"를 물으세요.

전통적인 투자 리서치는 업계 1위 기업과 이미 알려진 섹터만 주시합니다. 이 시스템은 반대로 갑니다. **물리적 공급망의 목줄(인후) 위치에서 출발해, 아무도 주목하지 않지만 일단 공급이 끊기면 업계 전체가 멈춰 서서 기다려야 하는 회사를 찾습니다.**

초과수익의 원천: 1차 병목(GPU, HBM, 전력)은 이미 충분히 가격에 반영되었습니다. 진짜 알파는 **2차, 3차 층**에 있습니다 — 광모듈, 레이저, InP 기판, SOI 웨이퍼, 에피택시 장비, 웨이퍼 레벨 테스트, IC 기판, 특수 유리섬유 등입니다.

## 1단계: 거대 트렌드 확인

### 1.1 트렌드 선별 기준

작은 유행 속에서 환상을 좇지 말고, 아래 조건을 모두 충족하는 거대 트렌드만 추적합니다.

| 기준 | 요구 사항 | 검증 방법 |
|------|------|---------|
| 지속성 | 최소 3-5년간 확실한 성장 | 업계 전망·설비투자 계획 검색 |
| 물리성 | 실제 하드웨어/소재/장비 구축이 필요함 | "소프트웨어 업그레이드"와 "물리적 증설"을 구분 |
| 규모성 | 글로벌 설비투자(capex) >500억 달러/년 | 선두 기업들의 capex 가이던스 검색 |
| 가속성 | 수요 증가 속도 > 공급 증설 속도 | 수요 성장률 vs 생산능력 확장 계획 비교 |

### 1.2 현재 추적 중인 거대 트렌드 목록

실행할 때마다 업데이트하며, 초기 목록은 다음과 같습니다.

1. **AI 인프라 구축** — 데이터센터, GPU 클러스터, 네트워크 인터커넥트, 전력
2. **에너지 전환** — 원전 재가동, 전력망 업그레이드, 에너지 저장
3. **국방 현대화** — 서방 국방비 상승 사이클, 공급망 재편
4. **반도체 재산업화** — 미국·유럽·일본의 보조금 기반 공장 건설, 장비/소재 병목
5. **우주 경제** — 위성 인터넷, 발사 빈도 급증

사용자가 구체적인 트렌드(예: "AI 인프라")를 지정했다면 해당 트렌드에만 집중합니다.

### 1.3 트렌드 검증 출력

```
트렌드 이름:
핵심 동인: (한 문장)
이미 발생한 검증 이벤트 (최소 3개):
  1. [날짜] [이벤트] [출처]
  2.
  3.
설비투자 규모: 글로벌 약 $XX 억/년, 증가율 YY%
수급 격차 판단: 수요 증가 속도 > 공급 증설 속도? 예/아니오/불확실
트렌드 확인: ✅ 추적 가능 / ❌ 근거 부족, 일단 추적 보류
```

## 2단계: 공급망 물리적 분해

### 2.1 계층별 분해 프레임워크

**개념 수준에 머무르지 말고, 물리적 실체까지 분해합니다.**

```
Layer 0(최종단): 최종 제품/서비스
    │
Layer 1(핵심 부품): 시장이 이미 충분히 주목하는 핵심 하드웨어
    │                 ⬆ 가격 반영 충분, 알파 제한적
    │─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
    │                 ⬇ 관심도 낮음, 알파 집중 구간
    │
Layer 2(하위 부품/소재): 핵심 부품을 떠받치는 부품과 소재
    │
Layer 3(상류 장비/원료): 하위 부품 제조에 필요한 장비와 원자재
    │
Layer 4(기반 인프라): 전력, 냉각, 토지, 인재, 인증
```

### 2.2 AI 인프라를 예로 든 분해 템플릿

```
Layer 0: AI 모델 학습/추론 서비스
Layer 1: GPU/가속기, HBM 메모리, 서버, 데이터센터
Layer 2 (집중 스캔 구간):
  ├─ 네트워크 인터커넥트: 광모듈, 광섬유, 스위치 칩, 구리 케이블
  ├─ 광통신 핵심: 레이저(EML/VCSEL/CW), 변조기, 광검출기
  ├─ 반도체 소재: InP 기판, GaAs 기판, SOI 웨이퍼, SiC 기판
  ├─ 첨단 패키징: CoWoS 기판, HBM TSV, ABF 기판 필름
  ├─ PCB/기판: 고주파·고속 PCB, IC 기판, 특수 유리섬유 직물
  ├─ 테스트: 웨이퍼 레벨 테스트(Probe Card), 번인(노화) 테스트, ATE
  ├─ 방열/냉각: 액체 냉각 시스템, CDU, 침지 냉각액
  └─ 전력 연결: 버스덕트, UPS, 배전반, 변압기
Layer 3:
  ├─ 에피택시 장비: MOCVD, MBE
  ├─ 노광/식각: 특수 파장 노광, InP 식각
  ├─ 원자재: 고순도 금속(인듐, 갈륨, 게르마늄), 특수가스, 스퍼터링 타깃
  └─ 인증/표준: MSA 표준, Telcordia 인증
Layer 4:
  ├─ 전력: 원자력, 천연가스 발전, 송변전
  ├─ 냉각수/방열 인프라
  └─ 데이터센터 부지/인허가
```

### 2.3 다른 트렌드의 분해

확인된 각 거대 트렌드에 대해 비슷한 분해를 수행합니다. WebSearch로 다음을 검색합니다.
- "{트렌드} supply chain bottleneck 2026"
- "{트렌드} shortage critical component"
- "{트렌드} capacity constraint"
- "{트렌드} sole source supplier"

## 3단계: 병목 식별 — "목줄" 찾기

### 3.1 병목 판정 6개 기준

Layer 2-3의 각 고리에 대해 항목별로 평가합니다.

| # | 기준 | 질문 | 점수 |
|---|------|------|------|
| 1 | **공급 집중도** | 글로벌 공급업체 ≤3곳인가? | 🔴 ≤2곳 / 🟡 3-5곳 / 🟢 >5곳 |
| 2 | **증설 주기** | 신규 생산능력 확보에 얼마나 걸리나? | 🔴 >2년 / 🟡 1-2년 / 🟢 <1년 |
| 3 | **대체 난이도** | 다른 기술/소재로 대체할 수 있나? | 🔴 대체 불가 / 🟡 일부 대체 가능 / 🟢 쉽게 대체 |
| 4 | **가동률** | 현재 생산능력 가동률은? | 🔴 >90% / 🟡 70-90% / 🟢 <70% |
| 5 | **수요 증가 속도** | 다운스트림 수요 증가율은? | 🔴 >50%/년 / 🟡 20-50% / 🟢 <20% |
| 6 | **고객 검증 주기** | 신규 공급업체 진입에 검증이 얼마나 걸리나? | 🔴 >1년 / 🟡 6-12개월 / 🟢 <6개월 |

**병목 등급**:
- 🔴🔴🔴 ≥4개 → **S급 병목** (단일 장애점 수준, 최우선)
- 🔴🔴 3개 → **A급 병목** (심각하게 제약됨)
- 🔴 1-2개 → **B급 병목** (압박은 있으나 통제 가능)
- 🔴 없음 → 병목 아님, 건너뜀

### 3.2 병목 지도 출력

```
공급망 병목 지도 — {트렌드 이름}
업데이트 날짜: YYYY-MM-DD

S급 병목 (단일 장애점):
  1. [고리 이름] — [원인 한 문장] — 공급업체: [회사 목록]
  2.

A급 병목 (심각한 제약):
  1.
  2.

B급 병목 (압박 있음):
  1.
  2.

최근 변화 (vs 지난 스캔):
  - [신규/격상/격하/해소] [고리 이름] — [원인]
```

## 4단계: 기업 선별 — 병목에서 종목으로

### 4.1 각 S급·A급 병목에 대해 관련 상장사를 모두 찾아냅니다


검색 방법:
- WebSearch "{병목 고리} supplier listed company"
- WebSearch "{병목 고리} manufacturer stock"
- WebSearch "{병목 제품} market share company"

### 4.2 1차 선별 기준 (빠른 필터링)

| 기준 | 요구 사항 | 이유 |
|------|------|------|
| 상장 여부 | 상장 완료 (A주/홍콩/미국/일본/대만/유럽) | 거래 가능 |
| 병목 사업 비중 | 매출의 >30%가 병목 고리에서 발생 | 순수도 |
| 시가총액 | <100억 달러 우선 | 대형주는 이미 충분히 가격에 반영됨 |
| 유동성 | 일평균 거래대금 >100만 달러 | 진입·청산 가능 |

### 4.2.1 밸류에이션 점검 (반드시 수행, 생략 불가)

**병목이 진짜라는 것 ≠ 투자 기회.** 모든 회사에 대해 PSR(PS)과 PER(PE)을 계산해 보고서에 표기해야 합니다. 아래 조합 조건으로 밸류에이션이 과도하게 선반영(고평가)되었는지 판단합니다.

#### 밸류에이션 빨간불 (하나라도 해당 → 신호 강도 상한 ★★, "⚠️ 밸류에이션 과열" 표기)

1. **시가총액 > TAM의 20%**: 회사 시가총액이 도달 가능한 시장 규모의 20%를 넘었다면, 성장 기대가 이미 과도하게 반영되었다는 뜻입니다
2. **PS > 30x 이면서 매출 증가율 < 100%**: 밸류에이션은 높은데 성장률이 이를 뒷받침하지 못합니다. 증가율 >100%인 회사는 PS 기준선에서 면제할 수 있지만, 여전히 "⚠️ 고평가, 고성장 지속 검증 필요"를 표기해야 합니다
3. **시가총액 > 5년 낙관 매출 전망의 10배**: 가장 낙관적인 가정이 모두 실현되더라도 현재 가격이 여전히 너무 높습니다
4. **유상증자 후 60일 내 주가 두 배**: 심리 주도 특징이 뚜렷하므로 신호 강도를 한 단계 낮춥니다

#### 밸류에이션 노란불 (추가 설명 필요, 없으면 등급 하향)

1. **적자 + PS > 15x**: ★★★까지는 허용하되 흑자 전환 경로와 일정표를 반드시 설명해야 합니다
2. **PS가 흑자를 내는 동종 기업의 5배 이상**: 프리미엄의 원천(시장점유율, 성장률 격차, 진입장벽 차이)을 반드시 설명해야 합니다
3. **PE > 80x**: PEG를 계산하고 성장률이 이를 뒷받침하는지 설명해야 합니다

#### 밸류에이션 초록불 (가점 항목)

- PS < 10x 이면서 매출이 성장 중 → 신호 강도를 한 단계 올릴 수 있습니다
- PE < 30x 이면서 해자가 있음 → "밸류에이션에 안전마진 있음" 표기

#### 밸류에이션 합리성 검증 (필수)

각 종목에 대해 다음 질문에 답합니다. "현재 시가총액으로 매수하고, 가장 낙관적인 시나리오가 모두 실현된다고 가정해 10년 뒤 25x PE로 매도한다면 연환산 수익률은 얼마인가?" 연환산 수익률 <10% → "현재 가격에는 안전마진이 없음"을 표기합니다.

**주의**: 밸류에이션 점검의 목적은 "PS 100배짜리 적자 회사"를 추천하는 식의 명백한 실수를 막는 것이지, 고평가된 초기 기업을 모두 배제하는 것이 아닙니다. 핵심은 성장률, TAM, 경쟁 구도가 현재 밸류에이션을 뒷받침할 수 있는지이며, 일률적으로 자르지 말고 구체적으로 분석해야 합니다.

**대만 주식 종목 데이터 수집**: 공급망 스캔에서는 대만 주식(4자리 숫자 코드, 예: 2330, 3661)이 자주 걸립니다. 시세/PER/시가총액/월별 매출은 모두 `python3 tools/twstock_data.py`(FinMind 데이터 소스, 사용법은 `skills/financial-data.md`의 대만 주식 장 참조)로 가져옵니다. 대만 상장사는 매월 10일 전까지 전월 매출을 의무 공시하며, 월별 매출의 전년 동월 대비 증감은 병목의 "물량·가격 동반 상승"을 검증하는 가장 빠른 공개 신호입니다.

## 5단계: 교차 검증 — 한 가지 이야기만 듣지 않기

### 5.1 정방향 검증

| 검증 항목 | 질문 | 검색 방법 |
|--------|------|---------|
| 고객 검증 | 주요 고객이 이미 계약/도입했는가? | 회사 공시, 고객사 실적 보고서 언급 검색 |
| 매출 검증 | 병목이 이미 매출 성장에 반영되었는가? | 최근 2-3개 분기 실적 보고서 검색 |
| 가격 검증 | 제품 가격이 오르고 있는가? | 업계 견적가, 애널리스트 리포트 검색 |
| 생산능력 검증 | 생산능력이 정말 빠듯한가? | 리드타임 데이터, 고객 불만 검색 |
| 자본 검증 | 증설 설비투자가 있는가? | 회사 capex 가이던스 검색 |

### 5.2 역방향 검증 (멍거식 부정)

| 역방향 질문 | 의미 |
|---------|------|
| 똑똑한 사람들은 왜 이 주식을 사지 않는가? | 이미 알려진 약세(bearish) 논거 찾기 |
| 이 병목은 우회될 수 있는가? 어떤 대체 경로가 있는가? | 기술 경로 리스크 |
| 중국/다른 플레이어가 생산능력을 빠르게 복제할 수 있는가? | 공급 충격 리스크 |
| 최종 수요가 50% 둔화되면 이 회사는 어떻게 되는가? | 하방 민감도 |
| 경영진이 과거 고점에서 유상증자로 지분을 희석한 적이 있는가? | 경영진 신뢰도 |
| 현재 밸류에이션에는 어떤 성장 가정이 내포되어 있는가? | 밸류에이션 합리성 |

### 5.3 신호 교차 검증

- 같은 병목에 속한 여러 회사가 모두 오르고 있는가? (업계 검증)
- 다운스트림 고객이 실적 보고서에서 공급 부족을 언급하는가? (고객 검증)
- 업계 협회/연구기관에 관련 데이터가 있는가? (제3자 검증)

## 6단계: 출력 — 병목 기회 대시보드

### 6.1 병목 기회 순위표

| 순위 | 회사 | 코드 | 시가총액 | 연매출 | PS | PE | 병목 고리 | 병목 등급 | 시장점유율 | 매출 증가율 | 신호 강도 | 밸류에이션 판단 |
|------|------|------|------|--------|-----|-----|---------|---------|---------|---------|---------|---------|
| 1 | | | | | x | x | | S/A | | | ★1-5 | 적정/다소 높음/과열 |

**필수 항목**: 시가총액, 연매출, PS, PE는 필수이며 "확인 필요"로 건너뛸 수 없습니다. 재무 데이터를 구할 수 없다면 신호 강도는 ★★를 넘을 수 없습니다.

신호 강도 등급 (밸류에이션 점검 결과가 등급에 직접 영향을 줌):
- ★★★★★ 다중 교차 검증, 고객 도입 완료, 매출 반영 완료, 밸류에이션 초록불 (PS 적정 + 흑자 또는 흑자 근접)
- ★★★★ 대부분의 검증 통과, 밸류에이션 초록불 또는 노란불 (설명 첨부 필요)
- ★★★ 논리는 성립하지만 일부 검증 대기, 밸류에이션 노란불 수용 가능 (예: 고성장 초기 기업)
- ★★ 초기 신호이거나, 병목 논리는 성립하지만 밸류에이션 빨간불 (시가총액 >TAM 20%, PS>30x 이면서 성장률 부족, 시가총액이 5년 전망을 크게 초과 등)
- ★ 순수 테마(콘셉트), 미검증

### 7.1 실행할 때마다의 증분 업데이트

1. 이미 식별된 병목이 여전히 유효한지 점검합니다
   - 새 공급업체가 진입했는가?
   - 생산능력이 병목을 해소할 만큼 확장되었는가?
   - 대체 기술에 돌파구가 생겼는가?

2. 새로 나타난 병목을 스캔합니다
   - 최근 7일간의 supply chain / shortage / bottleneck 뉴스를 검색합니다
   - 실적 시즌 중 공급망 관련 disclosure(공시)를 점검합니다

3. 병목 등급을 업데이트합니다 (격상/격하/해소)

## 매시간 스캔 모드 (예약 작업용)

매시간 한 번 실행하며, "건질 게 있을 때만 보고서를 낸다"는 방식을 따릅니다.

### 스캔 절차 (매시간)

1. **뉴스 스캔**: 지난 1-2시간의 공급망 관련 뉴스를 검색합니다
   - 키워드: supply chain bottleneck, shortage, capacity constraint, allocation, lead time, sole source, 병목(`瓶颈`), 품귀(`缺货`), 생산능력(`产能`), 가격 인상(`涨价`)
   - 범위: 영어 + 중국어 소스
2. **시장 신호**: 추적 중인 회사의 주가 변화를 점검합니다 (특히 >5%의 이상 변동에 주목)
3. **실적 보고서/공시**: 병목 관련 회사가 실적 보고서나 중대 공시를 냈는지 점검합니다
4. **밸류에이션 기회**: watchlist의 회사가 시장 하락 등의 이유로 매수 구간에 들어왔는지 점검합니다
5. **보고서 작성 여부 판단**:
   - 새 병목 신호, 명확한 종목 기회, 중대한 상태 변화가 있음 → **보고서 작성**
   - 새로운 발견 없음 → **보고서 작성 안 함**, 로그에만 "이번 회차 새 신호 없음"을 기록

### 보고서 출력 규칙

**하루에 폴더 하나**: `reports/bottleneck-map/YYYY-MM-DD/`

**파일 이름 규칙** (파일 이름만 보고 종목이 있는지 한눈에 알 수 있도록):

| 상황 | 파일 이름 형식 | 예시 |

| 명확한 종목 발견 | `HH-MM-标的代码1-标的代码2.md` (종목코드1-종목코드2) | `09-00-FORM-IBDN.md` |

## 핵심 원칙 (최우선)

1. **AI에게 주식을 추천하게 하지 말고, 공급망을 분해하게 하세요** — 질문이 답보다 중요합니다
2. **물리 우선** — 실제 물리적 제품/소재/장비가 필요한 고리에만 집중합니다
3. **2차, 3차 층** — 이미 충분히 가격에 반영된 선두 기업은 좇지 않습니다
4. **교차 검증** — 모든 결론에는 최소 2개의 독립적 출처가 있어야 합니다
5. **불확실성을 정직하게 마주하기** — 데이터를 찾지 못하면 "데이터 부족"이라고 쓰고, 추측으로 채우지 않습니다
6. **병목에는 유효기간이 있다** — 모든 병목은 결국 해소되며, 핵심은 시간 창을 판단하는 것입니다
7. **소형주 ≠ 좋은 기회** — 소형주도 형편없는 회사일 수 있으니, 반드시 재무 품질 관문을 통과해야 합니다
8. **병목이 진짜라는 것 ≠ 투자 기회** — 한 회사가 가장 빡빡한 병목 위에 앉아 있더라도, PS>30x이거나 여전히 적자라면 현재 가격은 매수 시점이 아닙니다. **밸류에이션은 절대적인 문턱이며, 병목 순수도·신호 강도·서사의 매력으로 덮어쓸 수 없습니다.** 오른 병목주 하나를 놓칠지언정, PS 100배에 적자 회사를 사지는 마세요
9. **CLAUDE.md의 객관성 원칙을 따르기** — 강세를 전제하지 말고, 데이터 먼저, 결론은 나중에
