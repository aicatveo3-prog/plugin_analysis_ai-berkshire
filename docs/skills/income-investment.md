# `/income-investment` · 배당·인컴 주식 분석

> 📄 원문: [skills/income-investment.md](https://github.com/xbtlin/ai-berkshire/blob/main/skills/income-investment.md) · 원문은 영어이며, 아래는 한국어 번역입니다.

::: tip 한눈에 보기
- **무엇을 하나요?** 배당주의 "표시 배당수익률"에 속지 않도록, 배당의 원천이 되는 현금흐름·부채·배당 이력·밸류에이션·세금·포트폴리오 적합성까지 따져서 이 회사가 믿을 만한 인컴 종목인지, 아니면 배당 함정인지 판정해 줘요.
- **언제 쓰나요?** 고배당주를 새로 살지 고민될 때, 이미 가진 배당주를 계속 들고 갈지·더 살지·줄일지 판단하고 싶을 때 써요.
- **사용 예:** `/income-investment "<company or ticker>" [mode=new|existing] [role=core-income|opportunistic-income|unspecified] ...` 형식이며, 예를 들어 `/income-investment "텐센트" mode=new`처럼 회사명만 넣어도 돼요.
- **결과물:** 정해진 18개 섹션으로 된 보고서가 `reports/{회사명}-income-investment-{YYYYMMDD}.md`에 저장되고, 보고서 감사(audit)까지 통과해야 완성본이 돼요.
- **핵심 특징:** 업종별로 다른 배당 커버리지 지표를 쓰고, 배당 삭감을 가정한 3가지 시나리오를 반드시 검토하며, 위험 관문(gate)에 걸리면 점수와 상관없이 탈락시키고, 7개 판정 중 딱 하나만 내려요.
:::

## 번역 전문

**원제:** 인컴 투자: 지속형·기회형 배당 분석

`$ARGUMENTS`를 분석해 다음 질문에 답합니다:

> 이 회사는 장기 인컴 확신 종목으로서든 기회형 고배당 포지션으로서든, 포트폴리오에서 역할을 맡길 만큼 충분히 지속 가능하고 매력적인 배당 가능 소득을 창출할 수 있는가?

높게 표시된 배당수익률을 좋은 기회의 증거로 여기지 마십시오. 이 워크플로는 학습과 리서치를 위한 것이며, 개인 맞춤형 투자 조언이 아닙니다.

## 입력

다음 명령 형식을 사용합니다:

```text
/income-investment "<회사명 또는 티커>" [mode=new|existing] [role=core-income|opportunistic-income|unspecified] [quantity=...] [cost_basis=...] [portfolio_weight=...] [target_yield=...] [tax_residence=...] [portfolio_file=...] [horizon=...]
```

회사명 또는 티커는 필수입니다. 나머지 항목은 모두 선택입니다. 같은 뜻의 자연어 입력도 받아들입니다. 누락된 값을 지어내지 마십시오: `Unknown`(알 수 없음) 또는 `Not calculable`(계산 불가)로 표시하고 그로 인한 영향을 밝히십시오. 특히 세금 거주지, 계좌 유형, 적용 조세조약, 확인된 원천징수 처리 방식 없이 세후 순소득을 추정하지 마십시오.

## 관련 워크플로

기존 워크플로를 다시 만들지 말고 사용하거나 참조합니다:

| 필요 | 워크플로 |
|---|---|
| 검증된 재무 데이터와 출처 간 대조 | `financial-data` |
| 전반적인 펀더멘털 전체 리서치 | `investment-research` |
| 매수 전 최종 결정 | `investment-checklist` |
| 포트폴리오 적합성, 집중도, 비중 결정 | `portfolio-review` |
| 결정 이후 모니터링 | `thesis-tracker` |
| 실적 발표 후 업데이트 | `earnings-review` |
| 개별 이벤트의 신속 분석 | `news-pulse` |

`income-investment`는 인컴에 특화된 결정을 담당합니다. 현재의 `portfolio-review` 결론을 조용히 뒤집어서는 안 됩니다.

## 리서치 원칙

1. 리서치 전에 `date`를 실행합니다. 데이터 기준일을 보고서 머리말에 적습니다.
2. 연차·중간 보고서, 실적 발표 자료, IR 자료, 규제 당국 공시, 공식 보도자료, 거래소 공식 데이터를 이 순서대로 우선합니다. 2차 출처는 빈 곳을 채우는 데만 쓰고 2차 출처임을 표시합니다.
3. `skills/financial-data.md`를 적용합니다: 결정에 핵심적인 재무 데이터는 가능하면 최소 2개의 독립 출처로 검증하고, 1%를 넘는 차이는 표시합니다.
4. 시점에 민감한 모든 수치에는 날짜나 기간을 붙입니다. 중요한 서술은 모두 **검증된 사실**, **추정**, **가정**, **분석적 판단**으로 구분합니다.
5. 정확한 배당성향, 배당수익률, 밸류에이션, 시가총액, 포트폴리오 소득, 시나리오 계산에는 `python3 tools/financial_rigor.py`를 사용합니다. 결정에 영향을 주는 결과를 암산에 의존하지 마십시오.
6. 보고서를 저장한 뒤 `tools/report_audit.py extract`와 `verdict` 워크플로를 실행합니다. 감사를 통과하지 못한 보고서는 초안일 뿐, 게시할 수 있는 리서치가 아닙니다.

## 실행 절차

### 1. 요청 파싱과 데이터 품질 확정

- 종목, 상장 시장, 통화, 배당 지급 통화, 모드, 원하는 역할, 선택 입력한 포트폴리오 정보를 확정합니다.
- 세전 소득, 세후 순소득, 매입가 대비 배당수익률(yield on cost), 포트폴리오 기여도, 거래 후 계산 중 어떤 것이 가능한지 밝힙니다.
- 근거 품질을 `A`(1차 자료 완비), `B`(1차 자료 일부), `C`(대부분 2차 자료/불완전)로 평가합니다. 펀더멘털 자료가 실질적으로 부족하면 `INSUFFICIENT DATA`(데이터 부족) 관문이 발동합니다.

### 2. 배당 이해하기

가능하면 최소 5년을 다룹니다:

- 지급 빈도; 정기·특별·변동 배당 여부; 지급 통화;
- 연간 주당 배당금과 총 배당액;
- 증액, 동결, 삭감, 중단 횟수;
- 배당 CAGR(정확한 기간과 특별배당 처리 방식 포함);
- 예상 공시일, 배당락일, 기준일, 지급일.

배당락일을 기다리는 것이 공짜 이익이 아님을 설명합니다: 이론적으로 주가가 배당만큼 조정되기 때문입니다. 배당 일정은 매매 타이밍에 참고할 수는 있지만, 부실한 회사를 사거나 필요한 매도를 미루는 근거가 되어서는 절대 안 됩니다.

### 3. 배당에 쓸 수 있는 현금 추적

순이익 기준 배당성향, 잉여현금흐름 기준 배당성향, 필수 투자 후 현금흐름, 현금흐름의 안정성과 질, 이자보상배율, 순부채, 부채 만기, 차환 필요성, 유지·성장 capex, 관련 부외 약정, 배당과 경쟁하는 자사주 매입을 분석합니다.

업종을 가리지 않고 EPS 기준 배당성향을 기계적으로 적용하지 마십시오:

| 업종 | 반드시 볼 업종별 지표 |
|---|---|
| REIT / SIIC | FFO, AFFO, 임대율, LTV |
| 은행 | CET1, 배당 가능 이익, 규제상 제약 |
| 보험사 | 지급여력과 자본 창출력 |
| BDC | NII, NAV, 무수익 여신(non-accruals) |
| 자원 | 경기 사이클 중간 기준 현금흐름과 변동 배당 정책 |
| 통신 / 유틸리티 | capex, 부채, FCF 커버리지 |

(역주: SIIC는 프랑스식 상장 부동산 투자회사, BDC는 미국의 사업개발회사, NII는 순투자이익입니다.)

### 4. 질과 지속성 검증

비즈니스 모델, 해자, 가격 결정력, 경기 민감도, 금리·환율·원자재 민감도, 소득의 예측 가능성, 자본 배분, 경영진의 질, 하방 시나리오에서 배당을 유지할 능력을 평가합니다. 회계상 이익과 반복 가능한 배당 가능 현금을 구분합니다.

### 5. 인컴 흐름의 가치 평가

현재 배당수익률, 과거 평균 배당수익률, 적절한 업종 멀티플, FCF 수익률, 합리적인 내재가치 범위, 안전마진, 그리고 주가 하락·배당 삭감이 겹친 시나리오를 분석합니다. 매입가 대비 배당수익률은 과거를 돌아보는 정보일 뿐이며, 포지션을 유지할 이유가 결코 되지 않습니다.

### 6. 실제 사용 가능한 소득 계산

입력이 뒷받침될 때만 연간 세전 배당금, 지급 주기별 세전 배당금, 알려진 원천징수액, 추정 세후 순소득, 포트폴리오 소득 기여도, 제안 거래 후 연간 소득을 계산합니다. 세금이나 계좌 정보가 불완전하면 세전 소득을 보여 주고, 세후 순소득을 계산할 수 없는 이유를 정확히 설명합니다. 조세조약 세율과 세금 처리 방식에는 관할 지역, 계좌 가정, 시행일을 표시합니다.

### 7. 포트폴리오 적합성 점검

포트폴리오가 제공된 경우:

- 현재 비중과 제안 비중을 정합니다;
- 업종·지역 집중도, 중복된 리스크, 한 산업에 대한 소득 의존도를 살핍니다;
- 자본의 분산과 배당의 분산을 구분합니다;
- 관련된 최신 `portfolio-review` 보고서가 있으면 읽습니다.

결론이 서로 다르면 두 결론을 모두 보여 주고 그 이유를 설명하며, 회사의 질과 배분 적합성을 분리합니다. 건전한 인컴 종목이라도 포트폴리오 집중도 때문에 `HOLD – DO NOT ADD`(보유 – 추가 매수 금지), `REDUCE`(비중 축소), `WATCHLIST`(관심 목록)가 적절할 수 있습니다.

데이터가 허락하면 월별 예상 세전 소득을 보여 줍니다. 배당이 없는 달을 채우려고 더 못한 회사를 추천하지 마십시오. 분기 배당 종목을 조합해도 월 배당 종목 없이 매달 현금흐름을 만들 수 있습니다.

### 8. 세 가지 시나리오 구성

기본, 비관, 심각 시나리오를 제시합니다. 각 시나리오에는 영업 가정, 배당 가능 현금흐름, 배당 커버리지, 재무상태표·차환 영향, 배당 결과, 밸류에이션 함의를 밝혀야 합니다. 비관·심각 시나리오에서는 배당이 고정되어 있다고 가정하지 말고, 배당 삭감을 명시적으로 검증해야 합니다.

## 분류, 관문, 판정

먼저 인컴 프로필을 분류합니다:

- **확신 + 지속형 인컴**: 우량한 사업, 지속 가능하며 늘어날 여지가 있는 배당, 장기 보유가 그럴듯함.
- **기회형 인컴**: 일시적인 고배당이나 할인으로, 진입·모니터링·보유 기간·청산 규칙이 명시되어 있음.
- **배당 함정(yield trap)**: 배당을 반복적으로 감당하지 못함, 레버리지·투자 수요와 양립할 수 없음, 구조적 쇠퇴, 또는 주로 주가 하락 때문에 높아진 배당수익률.
- **인컴 투자에 부적합**: 의미 있는 배당이 없음, 미미한 배당수익률, 근거 부족, 또는 주주환원이 주로 다른 방식으로 이루어짐.

다음 정성 평가표를 사용하되, 수치 평균은 계산하지 마십시오:

| 항목 | 평가(`Strong`, `Adequate`, `Weak`, `Critical`, `Unknown`) | 근거 |
|---|---|---|
| 사업의 질 | | |
| 현금흐름 가시성 | | |
| 배당 커버리지 | | |
| 재무상태표 건전성 | | |
| 배당 이력 | | |
| 배당 성장 잠재력 | | |
| 밸류에이션 | | |
| 경기 민감도 | | |
| 삭감 리스크 | | |
| 포트폴리오 적합성 | | |

(역주: 평가 등급은 각각 강함 / 적정 / 약함 / 심각 / 알 수 없음입니다.)

판정 전에 다음 차단 관문을 점검합니다:

- 배당을 반복적으로 감당하지 못함;
- 심각한 부채 또는 차환 리스크;
- 구조적인 사업 악화;
- 펀더멘털 데이터 부족;
- 중대한 지배구조 또는 신뢰성 문제.

안전성·부채·악화·신뢰성 관문 중 하나라도 통과하지 못하면 평가표보다 우선하며, 일반적으로 `REJECT / YIELD TRAP`(탈락 / 배당 함정)을 내려야 합니다(기존 보유 포지션인데 주어진 포트폴리오 정보만으로 즉시 처분을 결론 내릴 수 없다면 `REDUCE`). 데이터 부족 관문에 걸리면 `INSUFFICIENT DATA`를 내려야 합니다. 점수로 통과하지 못한 관문을 상쇄하지 마십시오.

판정은 정확히 하나만 내립니다:

- `CORE INCOME` (핵심 인컴)
- `OPPORTUNISTIC INCOME` (기회형 인컴)
- `WATCHLIST` (관심 목록)
- `HOLD – DO NOT ADD` (보유 – 추가 매수 금지)
- `REDUCE` (비중 축소)
- `REJECT / YIELD TRAP` (탈락 / 배당 함정)
- `INSUFFICIENT DATA` (데이터 부족)

판정에는 다음을 제시합니다: 가능한 포트폴리오 역할, 주된 이유, 주된 리스크, 진입 조건, 검토해 볼 비중 범위(누구에게나 적합한 범위는 결코 아님), 추가 매수 조건, 비중 축소/청산 기준, 모니터링 지표, 신뢰도. 포트폴리오·세금·위험 감내도 정보가 부족하면 확정적인 개인 맞춤 추천을 하지 마십시오.

## 필수 보고서 형식

다음 제목을 정확히 한 번씩 사용하고, 같은 분석을 반복하지 마십시오:

결과는 파일 시스템에서 안전한 회사 식별자를 써서 `reports/{회사명}-income-investment-{YYYYMMDD}.md`에 저장합니다. 2절에는 평가표와 차단 관문 결과를, 계산이 가능하면 11절에는 월별 소득 달력을, 18절에는 출처 제목, 발행 주체/발행처, 발행일, 접속일, 보고 기간, URL, 1차/2차 출처 표시를 포함합니다.

## 게시 전 감사

```bash
python3 tools/report_audit.py extract --report reports/{회사명}-income-investment-{YYYYMMDD}.md
# 추출된 모든 항목을 신뢰할 수 있는 출처와 대조해 검증한 뒤:
python3 tools/report_audit.py verdict --results '<검증된 JSON>' --report {회사명}-income-investment-{YYYYMMDD}.md
```

통과하지 못한 항목을 고치고 감사를 반복합니다. 해결되지 않은 공백은 가정으로 메우지 말고 분명히 남겨 두며, 신뢰도를 낮추십시오.
