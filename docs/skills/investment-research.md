## 리서치 프레임워크

버핏, 멍거, 돤융핑, 리루 네 투자 대가의 방법론을 바탕으로, 아래 일곱 개 모듈을 순서대로 실행해 리서치를 진행합니다.

### 사전 단계: AI 리서치 편향 자각 (반드시 실행)

리서치를 시작하기 전에 먼저 해당 기업의 'AI 리서치 가능성'을 평가하고, 잠재적인 데이터 편향을 식별합니다.

**정보 풍부도 등급**:
| 등급 | 특징 | AI 리서치의 함정 | 대응 전략 |
|------|------|-----------|---------|
| A등급 (정보 충분) | 상장된 지 여러 해, 증권사 커버리지 많음, 언론 보도 밀집 | 컨센서스가 지나치게 강해 AI 출력이 시장 가격에 수렴하므로 알파가 제한적임 | 반대 방향 검증에 집중합니다: 똑똑한 사람들은 왜 사지 않는가? 간과된 리스크는 무엇인가? |
| B등급 (정보 보통) | 상장 1~3년, 커버리지 제한적, 일부 데이터는 추정 필요 | AI가 '그럴듯한 추측'으로 빈칸을 메워, 겉보기엔 완전하지만 실제로는 허위의 확실성을 만들 수 있음 | 추정한 데이터마다 신뢰도를 표시하고, '근거 있는 추정'과 '근거 없는 채워 넣기'를 구분합니다 |
| C등급 (정보 희소) | 막 상장했거나 비인기 종목·신흥시장 종목, 커버리지가 거의 없음 | AI가 자료 부족 때문에 지나치게 보수적으로 판단해 '잘 안 보인다 = 나쁘다'로 오판함 | 제1원리 질문(아래 참조)을 사용해 제한된 정보에서 사업의 본질을 뽑아냅니다 |

**C등급 기업을 위한 제1원리 리서치법**:
공개 자료가 부족할 때는 '겉보기에 완전한' 보고서를 짜 맞추려 하지 말고, 다음과 같은 근본적인 질문에 집중합니다.
1. 고객은 누구인가? 왜 돈을 내는가? 대체 선택지가 있는가?
2. 재구매는 무엇이 이끄는가? 습관인가, 락인(lock-in)인가, 아니면 지속적으로 새로운 가치를 창출하기 때문인가?
3. 경쟁사가 100억을 들이면 이 사업을 복제할 수 있는가?
4. 경영진은 어떤 핵심 결정을 내렸는가? 그 결정은 어떤 판단력과 가치관을 보여 주는가?

**편향 자가 점검 체크리스트** (리서치 전 과정에서 경계를 유지할 것):
- [ ] 내가 느끼는 '확실성'은 사업의 본질에서 오는가, 아니면 자료의 양에서 오는가?
- [ ] 이 기업에 대한 자료량을 절반으로 줄인다면 내 결론이 바뀌는가?
- [ ] AI가 출력한 분석이 시장 컨센서스와 지나치게 비슷하지 않은가? 그렇다면 나의 정보 우위는 어디에 있는가?
- [ ] '공개 자료는 매우 적지만 사업 본질은 매우 좋은' 가능성이 과소평가되고 있지는 않은가?

정보 풍부도 등급 결과를 보고서 첫머리에 기재하고, 최종 결론에서는 'AI 리서치 신뢰도'와 '실제 투자 확실성'의 차이를 명시하세요.

### 1단계: 데이터 수집

> **데이터 소스 규범**: `skills/financial-data.md` 를 참조합니다. 모든 재무 데이터는 두 개의 독립된 출처에서 가져와야 하며, 오차가 1%를 넘으면 표시해야 합니다.
> - 미국 주식: macrotrends(주) + stockanalysis(보조)
> - 홍콩 주식: aastocks(주) + macrotrends ADR(보조)
> - A주(중국 본토 주식): 둥팡차이푸(주) + 쥐차오쯔쉰(보조)

Task 도구로 백그라운드 Agent를 실행해 인터넷에서 다음 데이터를 수집합니다.

1. 매출 구조: 최근 회계연도 및 최근 4개 분기의 부문별 매출, 성장률, 매출총이익률
2. 재무 지표: 최근 5년간 매출, 순이익, 매출총이익률, 영업이익률, 잉여현금흐름(FCF), 현금 보유액
3. 경쟁 구도: 시장점유율, 주요 경쟁사 비교
4. 비즈니스 모델과 해자: 핵심 경쟁우위의 원천
5. 기술 역량: 핵심 기술 스택, R&D 투자
6. 경영진: 창업자/CEO 이력, 지분율, 주요 의사결정 기록
7. 산업 전망: TAM(전체 도달 가능 시장), 성장 전망
8. 리스크 요인: 지정학, 규제, 공급망 등
9. 현재 밸류에이션: 시가총액, PER, PSR, PEG, EV/Revenue
10. 강세론과 약세론 양측의 핵심 논거

#### 데이터 교차 검증 (반드시 실행, 금융 엄밀성 도구 사용)

데이터 수집이 끝나면 **반드시 `tools/financial_rigor.py` 를 호출해 핵심 데이터를 프로그램으로 검증하고**, LLM의 암산 오류를 원천 차단합니다.

**반드시 검증해야 하는 데이터 항목**:
- 총 발행주식 수 (거래소, Yahoo Finance, StockAnalysis 등 최소 2개 출처에서 확인)
- 현재 주가와 시가총액 (**주가×총 발행주식 수를 직접 계산해 보고된 시가총액과 대조하고, 단위 오류를 방지합니다**)
- 최근 회계연도 매출과 순이익 (회사 연차보고서 + 최소 1개의 제3자 출처로 확인)
- 현금 보유액과 순현금 (현금+단기투자-총부채, 기준 차이에 주의)
- 경영진 지분율 (경제적 지분과 의결권을 구분하고, 차등의결권(AB주) 구조에 주의)

**필수 검증 단계 (Bash로 도구 호출)**:

Step 1 — 시가총액 검산 (부동소수점이 아닌 정밀 십진 연산):
```bash
python3 tools/financial_rigor.py verify-market-cap \
  --price {주가} --shares {총발행주식수} --reported {보고된시가총액} --currency {통화}
```

Step 2 — 핵심 데이터 다중 출처 교차 검증:
```bash
python3 tools/financial_rigor.py cross-validate \
  --field {필드명} --values '{"출처1": 수치, "출처2": 수치}' --unit {단위}
```
매출, 순이익, 현금 보유액에 대해 각각 실행합니다.

Step 3 — 밸류에이션 지표 정밀 검산 (PER/PBR/ROE/FCF Yield 등):
```bash
python3 tools/financial_rigor.py verify-valuation \
  --price {주가} --eps {EPS} --bvps {주당순자산} --fcf-per-share {주당FCF} --dividend {주당배당금}
```

**검증 규칙**:
1. 핵심 데이터 항목마다 최소 2개의 독립 출처를 확보합니다
2. 출처 간 차이가 발견되면 회사 연차보고서/거래소 데이터를 우선 채택하고, 차이의 원인을 명시합니다
3. **계산이 들어가는 모든 데이터는 반드시 도구로 검산하며, LLM의 암산을 금지합니다**
4. 도구 출력 결과는 보고서 부록 '핵심 데이터 교차 검증 기록'에 그대로 삽입합니다
5. 도구가 ❌ 편차 과대를 보고하면, 원인을 규명한 뒤에야 분석을 계속할 수 있습니다

**흔한 오류 예방**:
- 시가총액 단위: 홍콩달러 억 vs 위안화 억 vs 달러 억 — 0을 하나 빠뜨리거나 더 쓰기 쉽습니다
- FCF 기준: 출처마다 자본적 지출(capex)의 정의가 다를 수 있습니다 (리스, 인수 등의 포함 여부)
- 부채 기준: 운용리스 부채를 포함하는지 여부
- 지분율: 차등의결권(AB주) 기업의 경제적 지분 ≠ 의결권

### 2단계: 사업 본질 분석 — 돤융핑의 '옳은 사업'

분석 요점:
- 이 사업의 본질을 한 문장으로 정의합니다
- 매출 구조 분해 (차트)
- 5년간 수익성 추세 (차트)
- 비즈니스 모델 캔버스: 일회성 판매인가, 구독/재구매인가? 하드웨어인가, 소프트웨어인가, 플랫폼인가?
- 생태계 점착성/고객 락인 강도
- 매출총이익률 수준을 동종 업계와 비교하고, 왜 높은지/낮은지 설명합니다
- 영업 레버리지 분석
- **돤융핑식 추궁**: 이 사업은 어디가 좋은가? 한 문장으로만 설명해야 한다면 무엇인가?


### 3단계: 해자 평가 — 버핏의 '경제적 해자'

다섯 가지 유형의 해자를 하나씩 검증합니다.

| 해자 유형 | 검증 방법 |
|-----------|---------|
| 브랜드/가격 결정력 | 판매량 손실 없이 가격을 올릴 수 있는가? |
| 전환 비용 | 고객이 경쟁 제품으로 옮겨 가는 비용은 얼마나 높은가? |
| 네트워크 효과 | 사용자가 많아질수록 제품이 좋아지는가? |
| 규모의 경제 | 규모가 가져다주는 원가 우위는 얼마나 큰가? |
| 기술/특허 장벽 | 기술적으로 몇 년 앞서 있는가? 복제될 수 있는가? |

해자의 추세를 분석합니다: 지난 5년간 넓어졌는가, 좁아졌는가? 향후 5년은 어떻게 전망되는가?

**버핏식 추궁**: 10년 뒤에도 이 해자는 남아 있을까? 무엇이 이것을 무너뜨릴 수 있는가?

### 4단계: 역발상과 리스크 목록 — 멍거의 '거꾸로 생각하라'

- '이 기업이 실패할 수 있는 모든 경로'를 나열합니다 (표: 경로/확률/영향 정도)
- 역사적 유추: 역사상 비슷한 위치에 있었던 기업을 찾고, 그 결말이 어땠는지 봅니다
- 학제 간 분석: 네트워크 효과 이론, 기술 수용 곡선, 경쟁 게임이론 등의 모델로 교차 검증합니다
- 편향 자가 점검: 내러티브 편향, 앵커링 효과, 생존자 편향
- 약세론 측의 핵심 논거를 수집합니다

**멍거식 추궁**: 나는 어디에서 가장 틀리기 쉬운가? 똑똑한 사람들은 왜 이 기업을 사지 않거나 공매도하는가?

### 5단계: 경영진 평가 — 돤융핑의 '옳은 사람' + 버핏의 '경영진의 정직성'

- CEO/창업자 핵심 결정 복기 (표: 시기/결정/결과/점수)
- 자본 배분 능력: R&D 투자 수익률, 인수합병 성공률, 자사주 매입 타이밍
- 주주 이익과의 일치: 경영진 지분, 보상 구조, 지분 매각 기록
- 조직 역량: 팀 안정성, 핵심 인재 리스크
- 기업 문화의 특징

**돤융핑식 추궁**: CEO가 은퇴해도 이 기업은 경쟁력을 유지할 수 있는가?

### 6단계: 산업과 문명의 추세 — 리루의 '문명 진화 프레임워크'

- 해당 산업이 '문명 차원의 패러다임 전환' 한가운데 있는지 판단합니다
- 역사적 기술 혁명과의 유추 (증기기관/전기/인터넷/AI)
- TAM 성장 곡선과 천장 분석
- 산업 가치사슬에서 이 기업의 위치
- 기술 경로 리스크
- 고객/공급업체 집중도 분석

**리루식 추궁**: 20년 뒤에서 돌아본다면, 이 기업은 '이 시대의 스탠더드 오일'일까, 아니면 '반짝하고 사라진 3Com'일까?

### 7단계: 가치평가와 안전마진 — 버핏의 '내재가치' + 돤융핑의 '옳은 가격'

- 현재 시장 가격 (핵심 밸류에이션 지표 표) — **반드시 도구로 검산할 것**
- 역DCF: 현재 주가에는 어떤 성장 기대가 내재되어 있는가?
- 3가지 시나리오 가치평가 — **반드시 도구로 정밀 계산하고, 암산은 금지합니다**:
```bash
python3 tools/financial_rigor.py three-scenario \
  --price {주가} --eps {EPS} --shares {총발행주식수_억주} \
  --growth {낙관성장률} {중립성장률} {비관성장률} \
  --pe {낙관PER} {중립PER} {비관PER} --years 3 --currency {통화}
```
- 자체 과거 밸류에이션과 비교
- 동종 업계 밸류에이션과 비교

#### 장기 할인 가치평가 (10년 척도, 반드시 실행)

3년 3시나리오는 '비싼가, 싼가'에 답하고, 10년 할인은 '큰 비중을 실을 만한가'에 답합니다. **10년 IRR이나 잔존가치 배수를 제시하는 모든 리서치는 반드시 이 절차를 거쳐야 하며**, `tools/terminal_value.py` 를 사용합니다.

잔존가치 배수의 합법적인 출처는 단 하나, 영구성장모형뿐이며 **동종 업계 유추는 허용하지 않습니다**:

**PE(잔존가치) = (1 − g/ROIC) ÷ (r − g)**

> "디아지오가 13배이니 마오타이는 16배를 줘도 된다"는 순환논증입니다. 남의 오늘 가격으로 내가 가정한 가격이 합리적이라고 증명하는 셈입니다. 오늘 시장이 전반적으로 비싸다면, 유추법은 그 비쌈을 고스란히 10년 뒤로 옮겨 놓습니다.

**Step 1 — 세 가지 입력값을 정하고 각각 이유를 적습니다 (이 단계는 전부 판단이지 계산이 아니므로, 반드시 보고서에 설명해야 합니다):**

| 입력값 | 정하는 방법 | 흔한 실수 |
|---|---|---|
| **r** 자본비용 | 무위험이자율 + β × ERP. **통화는 반드시 현금흐름과 일치해야 합니다**: 위안화 기준 6%–9%(주로 8% 사용), 달러/홍콩달러 기준 9%–11.5%(주로 10% 사용) | 국채 금리를 그대로 따라감. 중국 국채 1.70%로 할인하면 PER이 50배 이상 나오는데, 그건 가치평가가 아니라 편향을 증폭하는 것입니다 |
| **ROIC** 정상상태 증분 자본수익률 | 기존 ROIC(장부에 잡히지 않는 무형의 해자를 포함하므로 높게 나옴)와 배당에서 역산한 내재 증분 ROIC(capex 수익률을 0으로 가정하므로 낮게 나옴) 사이에서 정합니다 | 기존 ROIC를 그대로 사용함. 새로 투자하는 1원 1원이 모두 위챗을 만들 때의 수익률을 재현한다고 가정하는 것과 같습니다 |
| **g** 영구성장률 | **향후 10년 성장률이 아닙니다** (그것은 이미 잔존가치 연도의 이익에 반영됨). 잔존가치 연도 이후 영원히 이어지는 성장률입니다. 절대 상한은 장기 명목 GDP입니다: 위안화 기준 기본 시나리오 ≤2%, 달러 기준 ≤4% | 달러의 g를 위안화의 r과 짝지음. 3% 명목 성장은 미국에서는 실질 0.5%(보수적)이지만 중국에서는 실질 2%(공격적)입니다 |

**g는 r에 따라 움직이지 않습니다** — g는 잔존가치 연도 이후 경제에 대한 판단이고, r은 내가 요구하는 수익률이므로 서로 독립된 두 가지입니다. 민감도 분석을 할 때는 r만 바꿉니다.

**Step 2 — 세 가지 강제 조건 통과 점검 (통과하지 못하면 가치평가를 보고서에 쓸 수 없습니다):**

```bash
python3 tools/terminal_value.py audit \
  --currency {CNY|USD|HKD} --r {자본비용} --roic {정상상태ROIC} \
  --g {비관g},{기본g},{낙관g} --rf {무위험이자율} --beta 1.0 \
  --discrete-risks "{리스크명}:{시나리오|꼬리구간|확률|미반영},..."
```

세 가지 점검의 내용과 반려 조건:

| # | 점검 | 반려 조건 |
|---|---|---|
| **C1** | **r과 g는 반드시 같은 통화여야 함** | r이 다른 통화의 구간에 있거나, 기본 시나리오 g가 자국 통화 상한을 넘는 경우. 도구가 "이것은 USD 수준입니다 — r은 자국 통화, g는 외화를 썼습니다"라고 바로 지적합니다 |
| **C2** | **분모 r−g ≥ 5%p** | 어느 한 시나리오라도 5%p에 못 미치는 경우. 분모가 좁을수록 g가 조금만 움직여도 가치평가가 뒤집히며, 분모가 ≤0이면 모형 실패로 바로 판정합니다. 상승/하락 시나리오가 꼭 필요하다면 `--upside-only` 로 명시적으로 선언하되, 보고서에 반드시 "이것은 시나리오이지 가치평가가 아닙니다"라고 적어야 합니다 |
| **C3** | **이산적 리스크는 r이나 β에 넣을 수 없음** | 어떤 리스크든 귀속을 `折现率`(할인율)/`r`/`beta` 로 적으면 일률적으로 반려합니다. 상장폐지, VIE 무효화, 지정학적 공급 중단, 규제 강타는 반드시 `情景`(시나리오) 또는 `尾部档`(꼬리 구간)으로 귀속해야 합니다. β가 1.0에서 벗어나면 반드시 `--beta-justification` 을 제시해야 합니다 |

**C3가 강제 조건인 이유**: r을 3%p 올리면 10년 차 현금흐름에 대한 페널티가 1년 차의 2.6배가 됩니다. 반면 상장폐지 리스크는 대체로 균일하거나 오히려 앞쪽에 몰린 연간 위험률입니다. **할인율로 이산적 리스크를 처리하면 리스크의 시간 분포를 체계적으로 거꾸로 뒤집게 됩니다.** 올바른 방법은 꼬리 시나리오 구간을 따로 만들고 그 구간에 확률을 부여하는 것입니다.

**C1/C2/C3에 대한 전체 논증은** `reports/7公司10年投资价值横评-确定性调整后回报-20260814.md` 의 3.4–3.6절을 참조하세요 (역주: '7개 기업 10년 투자가치 비교 — 확실성 조정 후 수익률' 보고서). 세 가지 모두 그 보고서가 실제로 밟았던 함정입니다.

**Step 3 — 수치 산출 (통과한 뒤에만 실행 가능):**

```bash
# 단일 시점 엑시트 PER, 전체 산식을 출력 (유보율/분자/분모를 모두 펼쳐 보여 주므로 보고서에 인용하기 편함)
python3 tools/terminal_value.py pe --roic {ROIC} --g {g} --r {r}

# IRR을 처음부터 계산
python3 tools/terminal_value.py irr \
  --profit {잔존가치연도이익} --mcap {오늘시가총액} --pe {엑시트PER} \
  --years 10 --payout {배당수익률-희석률}
```

여러 기업을 비교할 때는 파라미터를 JSON으로 작성해 `--config` 로 넘기고, `table` / `sweep` / `check` 를 사용합니다.

**Step 4 — 보고서에 반드시 적어야 하는 네 가지:**

1. **r 값, 통화, 그리고 짝을 이루는 g 상한**. r을 밝히지 않고 IRR을 보고하는 것은 자기 취향을 보고하는 것입니다.
2. **최소 두 가지 r 수준의 민감도, 그리고 각 수준에서 순위가 안정적인지 여부**. 절대 수치는 r에 좌우되며, 순위야말로 견고한 결론입니다.
3. **각 시나리오의 r−g 분모 폭**. 5%p 미만인 것은 반드시 '시나리오 참고용'이라고 표시합니다.
4. **모형에 반영하지 않은 이산적 리스크 목록** (audit에서 `未建模`(미반영)으로 표시한 것)을 '한계' 장에 적습니다.

**버핏식 추궁**: 이 r이 2%p 틀렸다면 내 결론이 뒤집히는가? 그렇다면 내 결론이 산 것은 기업인가, 할인율인가?

**돤융핑식 추궁**: 주식시장이 내일 문을 닫고 5년 동안 열리지 않는다 해도, 이 가격에 기꺼이 보유하겠는가?

## 출력 요구사항

1. 모든 분석에는 데이터 근거가 있어야 하며, 데이터 출처를 첨부합니다
2. 핵심 데이터는 Markdown 표로 제시합니다

## 데이터 표본 검수 (통과 절차)

보고서를 파일로 작성한 뒤에는 **반드시** 데이터 표본 검수를 실행하고, 통과해야만 게시할 수 있습니다.

**Step 1 — 표본 검수 목록 추출 (15% 무작위 추출):**
```bash
python3 tools/report_audit.py extract \
  --report <보고서 파일 경로>
```
JSON 템플릿이 출력되며, 각 항목에는 `fetched_value`(작성 대기)가 들어 있습니다.

**Step 2 — 데이터 조회 및 대조:**
목록의 각 데이터 항목에 대해 `skills/financial-data.md` 규범에 따라 신뢰할 수 있는 출처에서 데이터를 가져와
(미국 주식: macrotrends+stockanalysis, 홍콩 주식: aastocks+macrotrends, A주: 둥팡차이푸+쥐차오쯔쉰),
`fetched_value` / `fetched_source` / `fetched_value2` / `fetched_source2` 에 채워 넣습니다.

**Step 3 — 판정 출력:**
```bash
python3 tools/report_audit.py verdict \
  --results '<작성 완료한 JSON>' \
  --report <보고서 파일명>
```

- **【통과】**: 모든 표본 검수 항목의 편차 ≤ 1% → 보고서 게시 가능
- **【반려】**: 어느 한 항목이라도 편차 > 1% → 해당 데이터를 수정한 뒤 다시 표본 검수하며, 통과할 때까지 반복합니다

**Step 4 — 가치평가 기준 재점검 (10년 할인 가치평가가 들어간 보고서는 반드시 실행):**

보고서에 10년 IRR이나 잔존가치 배수가 등장한다면, 최종 확정본에 쓴 파라미터로 audit를 한 번 더 실행해, 보고서에 적힌 수치가 통과 당시와 일치하는지 확인합니다.

```bash
python3 tools/terminal_value.py audit \
  --currency {통화} --r {r} --roic {ROIC} --g {세가지g} --rf {무위험이자율} \
  --beta {β} --discrete-risks "{리스크귀속목록}"
```

- **【통과】** (종료 코드 0) → 보고서 게시 가능
- **【반려】** (종료 코드 1) → 수정한 뒤 다시 실행하며, 통과할 때까지 반복합니다

**이 단계를 건너뛸 수 없는 이유**: 7단계의 audit는 계산하기 전에 한 것이고, 보고서를 쓰는 과정에서 g나 r을 다시 조정하는 일이 자주 있습니다. **통과 직전의 마지막 audit야말로 보고서에 책임을 지는 audit입니다.**
