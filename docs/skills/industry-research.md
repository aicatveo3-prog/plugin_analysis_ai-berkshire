# `/industry-research` · 산업 공급망 전경 분석

> 📄 원문: [skills/industry-research.md](https://github.com/xbtlin/ai-berkshire/blob/main/skills/industry-research.md) · 원문은 중국어이며, 아래는 한국어 번역입니다.

::: tip 한눈에 보기
- **무엇을 하나요?** 하나의 투자 테마에서 출발해 "트렌드 → 수요 → 병목 → 수혜 공급망"으로 이어지는 논리 사슬을 검증하고, 공급망 전경도를 그린 뒤 각 단계의 대표 기업을 돤융핑·버핏·멍거·리루의 관점으로 분석해요.
- **언제 쓰나요?** 개별 종목이 아니라 원전·AI 인프라처럼 산업 전체를 놓고 "어느 단계에 돈이 몰리는지, 무엇을 사야 하는지" 판단하고 싶을 때 써요.
- **사용 예:** `/industry-research 원자력 발전`
- **결과물:** 홈 디렉터리에 `~/[行业名]产业链投资研究报告.md` 형식(〔산업명〕 공급망 투자 리서치 보고서)의 완성 보고서가 만들어지고, 데이터 표본 검수를 통과해야 게시돼요.
- **핵심 특징:** A주·홍콩·미국·해외 상장사 전수 스캔과 Tier 분류, 공급망 '목 조르기(병목) 단계' 식별, AI 리서치 편향 자각 체크, 핵심/위성/옵션 비중 제안까지 한 번에 해요.
:::

## 번역 전문

**원제:** 산업 투자 리서치: 공급망 전경 스캔 + 네 대가 개별 종목 분석 프레임워크

$ARGUMENTS 산업에 대해 체계적인 공급망 투자 리서치를 수행합니다.

## 리서치 목표

하나의 투자 테마/논리 사슬에서 출발하여 다음을 완성합니다.
1. 투자 논리 사슬의 모든 고리를 검증
2. 완전한 공급망 전경도 작성
3. 전 세계 모든 상장사 스캔(A주/홍콩 주식/미국 주식/기타 해외)
4. 각 세부 단계의 선두 기업에 대해 네 대가 프레임워크 분석 수행
5. 산업 단위 포트폴리오 배분 제안 출력

---

## 1단계: 투자 논리 사슬 구축과 검증

### 1.1 논리 사슬 그리기
화살표 사슬로 '근본 트렌드'에서 '수혜 종목'까지의 인과관계를 표현합니다. 예:
```
근본 트렌드 A
    → 수요 B를 유발
        → 병목/필수 수요 C를 창출
            → 수혜 공급망 D
```

### 1.2 고리별 검증
논리 사슬의 각 화살표에 의문을 제기하고 증거를 찾습니다.

| 고리 | 핵심 가정 | 검증 방법 | 데이터 출처 |
|------|---------|---------|---------|
| A→B | | 산업 데이터/전망 검색 | |
| B→C | | 수급 분석 검색 | |
| C→D | | 실제 사례/계약 검색 | |

### 1.3 '이미 일어난 검증 사건' 찾기
해당 논리 사슬을 뒷받침하는 **이미 체결되었거나 실현된 실제 비즈니스 사건**(전망이 아닌 것)을 나열합니다. 예: 대기업의 구매 계약, 정책 문서, 산업 보고서 등.

## 2단계: 공급망 전경도 작성

### 2.1 공급망 구조 그리기
산업을 업스트림 → 미드스트림 → 다운스트림 → 보조 단계로 분해합니다. 예:
```
업스트림: 원자재/자원 채굴 → 소재 가공/정제
미드스트림: 핵심 장비 제조 → 시스템 통합/엔지니어링 건설 → 신기술 연구개발
다운스트림: 운영/서비스 → 최종 고객
보조: 검사/인증 → 유지보수 서비스 → 금융 상품(ETF/신탁)
```

### 2.2 각 단계의 '사업 특성' 식별
각 단계에 다음을 표시합니다.

| 단계 | 비즈니스 모델 | 매출총이익률 구간 | 경쟁 구도 | 진입장벽 유형 | 경기 민감도 |
|------|---------|-----------|---------|---------|--------|
| | 자원 판매/장비 판매/서비스 판매/임대 수익 | | 독점/과점/완전경쟁 | 자원/인허가/기술/규모 | 강/중/약 |

### 2.3 '목 조르기(병목) 단계' 표시
공급망에서 공급이 가장 빠듯하고, 대체가 가장 어렵고, 이익률이 가장 높은 단계를 식별합니다. 이런 단계에 최고의 투자 종목이 있는 경우가 많습니다.

## AI 리서치 편향 자각: 산업 리서치의 특수한 함정

산업 리서치에서는 AI의 데이터 편향이 독특한 방식으로 증폭됩니다.

**산업 단위 편향**:
| 편향 유형 | 나타나는 모습 | 대응 |
|---------|------|------|
| 성숙 산업 선호 | 전통 산업(은행/에너지/소비재)은 자료가 매우 많아 AI 분석이 '더 확실해' 보임 | 확실성은 비즈니스 모델에서 나오지, 증권사 리포트의 양에서 나오지 않음 |
| 신흥 산업 과소평가 | 신산업(AI 응용/합성생물학 등)은 자료가 적어 AI 분석이 보수적으로 치우침 | '현재 데이터'가 아닌 '최종 국면(엔드게임) 사고'로 산업 가치를 판단 |
| 선두 기업 선호 | 대기업 자료가 소기업보다 훨씬 많아 AI는 본능적으로 선두 기업을 추천하는 경향이 있음 | 소기업이 더 나은 위험 대비 수익을 가질 수 있으니, AI 분석 분량이 짧다는 이유로 무시하지 말 것 |
| 상장사 선호 | 상장사만 스캔하면 공급망 내 핵심 비상장 플레이어를 놓침 | 반드시 비상장사를 검색하고 '향후 IPO 후보'로 표시 |
| 영어 선호 | AI는 영어 자료 처리 능력이 더 강해 중국/아시아 시장 플레이어를 과소평가할 수 있음 | 반드시 중국어와 영어 정보원을 함께 검색 |

**공급망 스캔에서의 편향 방지 조치**:
1. 각 단계마다 'AI가 쉽게 찾는 회사'만 나열하지 말고, '잘 알려지지 않았지만 우량할 수 있는 종목'도 적극적으로 검색합니다.
2. 정보가 부족한 소형주는 분석 분량이 짧다는 이유로 추천도를 낮추지 않습니다. 보고서 길이가 아니라 핵심 질문(사업의 본질, 해자, 경영진)으로 평가합니다.
3. 최종 보고서에 각 회사의 '정보 충분도'(A/B/C 등급)를 표시하여, AI 분석의 신뢰 수준을 독자가 알 수 있게 합니다.

## 3단계: 전 세계 상장사 스캔

Task 도구로 백그라운드 Agent를 실행해 해당 산업의 모든 상장사를 전면 검색합니다.

### 검색 목록
- 미국 주식(NYSE/NASDAQ/NYSE American) 관련 기업
- A주(상하이/선전) 관련 기업
- 홍콩 주식 관련 기업
- 기타 해외 시장(일본/한국/유럽/호주 등)
- 산업 ETF
- 핵심 비상장사(향후 IPO 가능성)

### 각 회사에 대해 수집할 항목
- 회사명(중국어·영어)
- 종목 코드와 거래소
- 시가총액(대략치)
- 한 줄 설명(공급망 내 위치와 역할)
- 순수 종목 여부(순수 원전 기업 vs 다각화 기업 중 원전 사업 보유)
- 소속 공급망 단계

### 출력 형식
공급망 단계별로 분류하여, 단계마다 스캔한 모든 회사를 담은 표를 하나씩 만듭니다.
그다음 투자 확실성에 따라 계층을 나눕니다.
- **Tier 1**: 대형주, 순수 종목, 산업 선두
- **Tier 2**: 중형주, 순수 종목 또는 높은 사업 비중, 세부 분야 선두
- **Tier 3**: 소형주, 개발 단계, 고위험·고탄력
- **Tier 4**: 다각화 기업 중 관련 사업을 보유한 대기업

## 4단계: 단계별 선두 기업 네 대가 분석

각 공급망 단계의 **Tier 1 및 Tier 2 기업**에 대해 아래 분석을 수행합니다(Tier 3/4 기업은 간단한 코멘트로 충분합니다).

### 4.1 사업의 본질(돤융핑)
- 이 회사가 공급망에서 무엇을 하는지 한 문장으로 정의
- 매출 구조와 성장률
- 매출총이익률/순이익률 수준과 추세
- 현금흐름 특성
- **추가 질문**: 이것은 좋은 사업인가? 왜 그런가?

### 4.2 해자(버핏)
다섯 가지 해자로 점수를 매깁니다(★1-5).

| 해자 | 강도 | 근거 |
|--------|------|------|
| 브랜드/가격 결정력 | | |
| 전환 비용 | | |
| 네트워크 효과 | | |
| 규모의 경제 | | |
| 기술/인허가 장벽 | | |

**추가 질문**: 10년 뒤에도 해자가 남아 있을까?

### 4.3 리스크(멍거)
- 이 회사는 어떤 식으로 실패할 가능성이 가장 큰가?
- 최악의 시나리오에서 가치는 얼마인가?
- 똑똑한 사람들은 왜 이 종목을 사지 않는가?

### 4.4 경영진(돤융핑+버핏)
- CEO/창업자는 누구인가? 주요 의사결정 기록
- 지분율과 이해관계 일치 여부
- 간단 평가(A/B/C 등급)

### 4.5 밸류에이션 스냅숏
- 현재 PER/PSR/EV/EBITDA
- 같은 단계의 경쟁사와 비교
- 간단 평가: 비싸다/적정하다/싸다

### 4.6 추천도
★1-5로 표시합니다.
- ★★★★★ = 핵심 비중 후보
- ★★★★☆ = 위성 비중 후보
- ★★★☆☆ = 관찰 목록
- ★★☆☆☆ = 고위험 옵션
- ★☆☆☆☆ = 추천하지 않음

## 5단계: 산업 단위 리스크 평가(멍거의 '체크리스트')

### 5.1 시스템 리스크 목록

| 리스크 | 확률 | 영향 | 대응 전략 |
|------|------|------|---------|
| 투자 논리 사슬의 특정 고리가 반증됨 | | | |
| 대체 기술 등장 | | | |
| 정책/규제 블랙스완 | | | |
| 수요의 경기순환적 조정 | | | |
| 밸류에이션 거품 붕괴 | | | |

### 5.2 역사적 유사 사례
역사상 비슷했던 공급망 투자 테마를 찾아 최종 결말을 분석합니다.
- 유사 산업은 무엇인가?
- 최종 승자는 누구였는가? (업스트림/미드스트림/다운스트림?)
- 대다수 투자자는 돈을 벌었는가, 잃었는가?
- 현재 산업에 주는 시사점은 무엇인가?

### 5.3 편향 자가 점검
- 서사 편향: 이야기가 너무 완벽하지 않은가?
- 앵커링 효과: 최근 상승폭에 기준점이 묶여 있지 않은가?
- 군중 심리: '모두가 사고 있어서' 사려는 것은 아닌가?

## 6단계: 문명 트렌드 판단(리루 프레임워크)

- 이 산업이 기대고 있는 근본 트렌드는 '문명 차원의 패러다임 전환'인가, '일시적 열풍'인가?
- 역사상 가장 가까운 기술 혁명 유사 사례는 무엇인가?
- 10~20년 뒤 이 산업의 최종 국면은 어떤 모습인가?
- 공급망에서 '승자독식'이 나타날 가능성이 가장 큰 단계는 어디인가?
- 파괴적 혁신에 밀려날 가능성이 가장 큰 단계는 어디인가?

## 7단계: 포트폴리오 배분 제안

### 7.1 추천 포트폴리오
다음 구조로 출력합니다.

| 층 | 비중 | 종목 | 소속 단계 | 핵심 논리 |
|------|---------|------|---------|---------|
| **핵심 비중** | 테마 비중의 50-60% | | | 가장 확실하고 해자가 가장 넓음 |
| **위성 비중** | 테마 비중의 25-35% | | | 탄력이 크고 확실성은 다소 낮음 |
| **옵션 비중** | 테마 비중의 5-15% | | | 고위험·고수익, 0이 될 수도 있음 |
| **ETF 대안** | 위 전부를 대체 가능 | | | 종목을 고르고 싶지 않은 사람을 위한 '게으른 투자자용 해법' |

### 7.2 매수/매도 신호

| 신호 유형 | 구체적 조건 |
|---------|---------|
| 추가 매수 신호 | |

| 전량 매도 신호 | |

### 7.3 테마 비중 상한 제안
투자 논리 사슬의 확실성과 위험 정도에 따라, 이 테마가 전체 포트폴리오에서 차지할 상한 비율을 제안합니다.

## 출력 요구사항

1. 모든 분석은 데이터로 뒷받침하고 데이터 출처를 첨부할 것
2. 핵심 데이터는 Markdown 표로 제시할 것
3. 공급망 전경도는 코드 블록 안의 텍스트 도표로 표현할 것
4. 각 단계마다 선두 기업을 최소 2-3곳 분석할 것
5. 전 세계 기업 스캔은 가능한 한 빠짐없이 할 것(A주/홍콩 주식/미국 주식/기타 해외)
6. 최종적으로 완성된 보고서를 `~/[行业名]产业链投资研究报告.md`에 저장할 것 (역주: 파일명은 "〔산업명〕 공급망 투자 리서치 보고서.md"라는 뜻)
7. 결론은 명확히 하고, 구체적인 종목·비중·가격 구간을 제안할 것
8. 각 분석 모듈 끝에 해당 대가의 '추가 질문'을 둘 것

## 데이터 표본 검수(게시 허용 절차)

보고서를 저장한 뒤 데이터 표본 검수를 수행하고, 통과해야만 게시할 수 있습니다.

```bash
# Step 1 — 표본 검수 목록 추출(15% 무작위 표본)
python3 tools/report_audit.py extract \
  --report <보고서 파일 경로>

# Step 2 — 목록의 각 항목을 신뢰할 수 있는 출처에서 확인(skills/financial-data.md 참고)

# Step 3 — 통과/반려 판정 출력
python3 tools/report_audit.py verdict \
  --results '<작성한 JSON>' \
  --report <보고서 파일명>
```
