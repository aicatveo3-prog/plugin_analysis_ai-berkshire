# `/industry-funnel` · 업종 깔때기 선별

> 📄 원문: [skills/industry-funnel.md](https://github.com/xbtlin/ai-berkshire/blob/main/skills/industry-funnel.md) · 원문은 중국어이며, 아래는 한국어 번역입니다.

::: tip 한눈에 보기
- **무엇을 하나요?** 업종이나 투자 테마 하나를 받아 A주·홍콩·미국·해외·비상장 기업까지 30~60개를 훑고, 가치투자 기준으로 걸러 최종 3개 종목을 골라요.
- **언제 쓰나요?** 'AI 연산 인프라', '혁신 신약', '로봇'처럼 관심 있는 테마는 있는데 어떤 종목을 깊이 볼지 정하지 못했을 때 써요.
- **사용 예:** `/industry-funnel AI 연산 인프라`
- **결과물:** `reports/{산업명}-funnel-{YYYYMMDD}.md` 보고서에 단계별 선별 결과, 최종 3개 종목 포트폴리오 표, 비중 제안이 정리돼요.
- **핵심 특징:** 단계마다 탈락 이유를 남겨 나중에 복기할 수 있어요. 점수 순이 아니라 포트폴리오 상호보완성으로 최종 종목을 고르고, AI의 대형주·영어 자료 편향도 따로 점검해요.
:::

## 번역 전문

**원제:** 업종 깔때기 선별: 전체 시장에서 3개 기업까지 좁혀 가는 가치투자 정선 절차

$ARGUMENTS 업종/테마에 대해 깔때기식 가치투자 선별을 수행하며, 전체 시장 스캔에서 시작해 단계별로 걸러 최종 3개 종목을 선정합니다.

## 적용 상황

사용자가 하나의 업종이나 투자 방향(예: "AI 연산 인프라", "혁신 신약", "로봇")을 말하며 다음을 원할 때:
1. 중요한 종목을 하나도 빠뜨리지 않는다 (A주, 홍콩 주식, 미국 주식, 비상장 후보 포함)
2. 통일된 기준으로 '스토리 주식'과 질이 부족한 기업을 걸러 낸다
3. 정말 깊이 연구할 가치가 있는 상위 3개 기업에 에너지를 집중한다
4. 단계마다 명확한 유지/탈락 기준이 있어 복기하고 추적할 수 있다

`industry-research` 와의 차이:
- `industry-research` 는 산업 가치사슬의 구조와 전경에 중점을 두고, 단계별로 잘라 봅니다
- `industry-funnel` 은 개별 종목 선별 깔때기에 중점을 두고, 전체 시장에서 단계적으로 3개 기업까지 좁힙니다

두 스킬은 상호 보완할 수 있습니다: 먼저 `industry-research` 로 산업 가치사슬의 구도를 파악한 뒤, `industry-funnel` 로 종목을 정선합니다.

## 깔때기 구조 개요

```
1단계: 전체 시장 스캔       30-60개   (거래 활발도+상승률+시가총액 상위 30의 합집합)
        ↓ 가치투자 5대 필수 지표
2단계: 1차 선별             ≤ 10개   (5개 항목 모두 합격 + 해자 ★★★ 이상)
        ↓ 정밀 분석
3단계: 정밀 분석            ≤ 10개   (기업당 300-500자 구조화 분석)
        ↓ 최종 선정
4단계: 네 대가 심층 분석     3개      (기업당 800-1200자, 버핏·멍거·돤융핑·리루 네 관점)
        ↓
출력: 투자 제안 + 매매 신호 + 비중 제안
```

각 단계에서 '걸러 낸 종목'은 반드시 탈락 이유를 남겨야 하며, 블랙박스로 처리해서는 안 됩니다.

---

## 1단계: 전체 시장 스캔 입구

### 1.1 활발한 종목의 정의 (세 가지 유형의 합집합)

**A 유형 - 거래 활발도**:
- 최근 30일 일평균 거래대금 순위가 업종 상위권 (A주/홍콩 주식/미국 주식 각각 상위 30개)

**B 유형 - 상승률 순위**:
- 최근 30일 상승률 상위 20개
- 최근 90일 상승률 상위 20개
- 두 목록의 합집합

**C 유형 - 시가총액 기준**:
- 업종 내 시가총액 상위 30개 (등락과 무관)

최종 스캔 풀 = A ∪ B ∪ C, 예상 30-60개.

### 1.2 반드시 검색해야 하는 시장

| 시장 | 권장 출처 |
|------|---------|
| A주 (상하이·선전) | 퉁화순/둥팡차이푸 업종 섹터, 퉁다신 |
| 홍콩 주식 | 푸투/퉁화순 홍콩 주식, HKEX 업종 분류 |
| 미국 주식 | NASDAQ/NYSE 업종 ETF 보유 종목, Yahoo Finance |
| 해외 시장 | 일본·한국·대만·유럽의 관련 기업을 빠뜨리지 말 것 (특히 반도체, 전자) |
| 비상장 기업 | '향후 IPO 후보' 소절을 따로 두고, 최신 기업가치와 예상 IPO 시기를 명시 |

### 1.3 출력 형식

| 회사명 | 코드 | 시장 | 시가총액 | 주력 사업 한 줄 | 해당 업종 비중 | 선정 유형(A/B/C) |
|-------|------|-----|------|----------|-----------|----------------|

**핵심 자가 점검**:
- 해당 업종 비중이 < 30%인 '곁다리 종목'은 신중하게 다루고, '순수 종목 아님'으로 표시합니다
- 중국/아시아 시장 종목을 영어 자료가 적다는 이유로 빠뜨리지 않습니다
- 소형주를 AI가 대형 선도주를 선호한다는 이유로 빠뜨리지 않습니다

## 2단계: 가치투자 5대 필수 지표로 1차 선별 → ≤ 10개

1단계의 30-60개 기업에 대해 5대 필수 지표를 하나씩 적용합니다.

### 2.1 5대 필수 지표

| # | 지표 | 통과 기준 | 완화 조건 | 데이터 출처 |
|---|------|---------|---------|---------|
| 1 | PER 밸류에이션 | 합리적 수준 (과거 구간, 동종 업계와 비교) | 고성장 기업은 PEG < 1.5까지 완화 가능 | 실적 보고서+Wind/퉁화순 |
| 2 | ROE | > 15% 또는 최근 3년 추세 개선 | 자산 집약 업종은 완화 가능 | 실적 보고서 |
| 3 | 영업현금흐름 | 양수이며 순이익 대비 > 70% | — | 실적 보고서 |
| 4 | 부채비율(자산 대비) | < 60% | 유틸리티/전력은 70%까지 완화 가능 | 실적 보고서 |
| 5 | 해자 간이 평가 | ★★★ 이상 | — | 정성적 판단 |

**해자 5가지 유형**:
- 브랜드/가격 결정력
- 전환 비용/사용자 점착성
- 네트워크 효과
- 규모의 경제
- 기술/인허가/자원 장벽

### 2.2 출력 형식

| 기업 | PER | ROE | 현금흐름/순이익 | 부채비율 | 해자 | 종합 | 유지/탈락 | 탈락 이유 |
|------|----|----|-----------|-------|-------|------|------|---------|

**유지 규칙**:
- 5개 항목 모두 합격 → 바로 유지
- 4개 항목 합격 + 1개 항목 근접 → 유지하되 노란색 표시
- 4개 항목 미만 → 탈락, 이유를 명시

**목표**: ≤ 10개를 유지합니다. 너무 많이 남으면(> 12) 해자 기준을 ★★★★로 올려 한 번 더 선별합니다.

## 3단계: 정밀 분석 (≤ 10개, 기업당 300-500자)

1차 선별에서 남은 기업을 하나씩 구조화해 분석합니다.

### 3.1 기업별 분석 템플릿

```
## {회사명}（{코드}）

**한 문장 비즈니스 모델**:
(무엇을 팔고, 누구에게 팔고, 어떻게 돈을 받는가)

**재무 품질**:
- 매출 성장률 / 이익 성장률 / 매출총이익률 / ROE / 현금흐름
- 핵심 변화 (최근 1-2년 사이 가장 중요한 재무적 전환점)

**해자의 깊이**:
- 주요 해자 유형 + 구체적 증거
- 5년 뒤에도 해자가 남아 있을지에 대한 간단한 판단

**주요 리스크 (상위 3개)**:
1.
2.
3.

**밸류에이션 간이 평가**:
- 현재 PER/PSR/EV/EBITDA + 과거 구간 내 위치
- 동종 업계 비교
- 한 문장 결론: 비쌈 / 적정 / 저렴

**최종 3개에 진입하는가?**: 예 / 아니오 (이유)
```

### 3.2 최종 3개 기업의 선정 기준

점수 순으로 상위 3개를 고르는 것이 아니라, '포트폴리오 상호보완성'에 따라 고릅니다:
- 최소 1개는 '높은 확실성, 낮은 변동성' (버핏형)
- 최소 1개는 '중간 확실성, 중간 변동성' (성장형)
- 선택적으로 1개는 '높은 변동성, 높은 리스크' (옵션형)

어떤 세부 분야에서 충분히 좋은 기업을 3개 찾지 못했다면, 억지로 숫자를 채우지 말고 차라리 '최종 선정 2개 + 관찰 1개'라고 씁니다.

## 4단계: 네 대가 심층 분석 (3개, 기업당 800-1200자)

최종 선정된 3개 기업에 대해 네 대가의 관점으로 심층 분석을 수행합니다.

### 4.1 돤융핑의 관점: 사업의 본질

- 이 기업이 어떤 사업을 하는지 한 문장으로 정의합니다
- 이것은 좋은 사업인가? 왜 그런가?
- 이 기업의 '본분'(역주: 돤융핑이 강조하는 개념으로, 해야 할 일을 하고 하지 말아야 할 일은 하지 않는 원칙)은 무엇인가? 경영진이 그것에서 벗어난 적은 없는가?
- 비즈니스 모델의 '지속성'은 어디에 있는가?

### 4.2 버핏의 관점: 해자의 깊이

- 다섯 가지 유형의 해자로 점수를 매기고(★1-5), 구체적 증거를 나열합니다
- 10년 뒤에도 해자가 남아 있는가?
- 지금 매수할 때의 '안전마진'은 어디에 있는가?

| 해자 | 강도 | 구체적 증거 |
|-------|------|---------|
| 브랜드/가격 결정력 | | |
| 전환 비용 | | |
| 네트워크 효과 | | |
| 규모의 경제 | | |
| 기술/인허가 장벽 | | |

### 4.3 멍거의 관점: 리스크와 실패 양상

- 이 기업은 어떻게 실패할 가능성이 가장 높은가? (실패 경로 상위 3개를 나열)
- 최악의 시나리오에서는 얼마의 가치가 있는가? (최소한의 간이 가치평가)
- 똑똑한 사람들은 왜 사지 않는가? (반대 논증)
- 도덕/컴플라이언스/경영진 리스크가 있는가?

### 4.4 리루의 관점: 문명 차원의 추세 속 위치

- 이 기업이 속한 분야는 '문명 차원의 패러다임 전환'인가, '일시적 열풍'인가?
- 역사상 가장 비슷한 기술 혁명은 무엇인가?
- 10-20년 뒤 이 기업의 최종 모습은?
- 승자독식 구도인가?

### 4.5 종합 추천도

```
추천도: ★★★★☆
비중 유형: 핵심 / 위성 / 옵션 / 관찰
권장 매수 구간: 현재가 / N% 조정 시 / 인내심을 갖고 기다림
권장 보유 비중: 해당 테마 비중의 X%
핵심 모니터링 지표: (이 기업의 투자 논리가 뒤집히는 신호는 무엇인가)
```

## 5단계: 종합 출력

보고서 말미에 다음을 통합합니다.

### 5.1 최종 3개 기업 포트폴리오 표

| 기업 | 유형 | 추천도 | 권장 비중 | 핵심 논리 | 핵심 리스크 |
|------|------|-------|---------|---------|---------|
| A | 핵심 | ★★★★★ | 50-60% | | |
| B | 위성 | ★★★★☆ | 25-35% | | |
| C | 옵션 | ★★★☆☆ | 5-15% | | |

### 5.2 업종 ETF 대안

종목을 직접 고르고 싶지 않다면, 관련 ETF 1-3개(A주/홍콩 주식/미국 주식)를 나열합니다.

### 5.3 업종 전체의 위치 판단

- 업종 PER/PBR의 과거 백분위
- 자금 흐름 (북향자금(역주: 홍콩→중국 본토 투자 자금), ETF 설정·환매, 셀사이드(증권사) 커버리지 밀도)
- 업종 전체가 '초기/확장/성숙/쇠퇴' 중 어느 단계에 있는가

### 5.4 정보 충분도 자가 평가 (필수)

| 차원 | 등급 | 설명 |
|-----|------|-----|
| 기업 재무 데이터의 완전성 | A/B/C | |
| 밸류에이션 데이터의 시의성 | A/B/C | |
| 업종 구도 판단 | A/B/C | |
| 경영진 정보 | A/B/C | |

A = 데이터가 충분하고 신뢰할 수 있음; B = 일부 누락이 있으나 주요 결론에는 영향 없음; C = 누락이 많아 결론을 신중히 다뤄야 함.

### 5.5 업데이트 대기 데이터 항목

어떤 데이터가 추정치인지, 어떤 데이터를 나중에 확인해야 하는지, 어느 분기 실적 보고서를 중점적으로 추적해야 하는지 명확히 나열합니다.

### 5.6 자료 출처 목록

각 데이터/결론의 출처 링크를 분류해 나열합니다 (실적 보고서, 증권사 리포트, 뉴스, 업종 보고서).

## AI 리서치 편향 자각 (중요)

깔때기 선별 과정에서 AI가 빠지기 쉬운 함정:

| 편향 | 나타나는 모습 | 대응 |
|------|-----|------|
| 선도주 선호 | 대형주는 자료가 많고 분석 분량도 길어서 '더 좋아' 보임 | 보고서 분량이 아니라 필수 지표와 해자 점수로 순위를 매깁니다 |

## 출력 요구사항

1. **보고서 위치**: `reports/{산업명}-funnel-{YYYYMMDD}.md` (업종 보고서는 reports/ 루트 디렉터리에 둡니다)
2. **언어**: 중국어
3. **문체**: 직설적이고 날카롭게, 군더더기 없이
4. **데이터**: 모든 데이터에 출처를 표시하고, 추정치에는 '추정'이라고 표시합니다
5. **입장을 미리 정하지 않음**: 먼저 데이터를 제시 → 논리를 전개 → 결론을 냅니다
6. **양면 검토**: 핵심 판단마다 반대 논거를 덧붙입니다
7. **단계마다 탈락 기록을 남김**: 탈락한 기업도 이름+이유를 남깁니다

## 데이터 표본 검수 (통과 절차)

보고서를 작성한 뒤 데이터 표본 검수를 실행하고, 통과해야만 게시할 수 있습니다.

```bash
# Step 1 — 표본 검수 목록 추출 (15% 무작위 추출)
python3 tools/report_audit.py extract \
  --report <보고서 파일 경로>

# Step 2 — 목록의 각 항목을 신뢰할 수 있는 출처에서 조회 (skills/financial-data.md 참조)

# Step 3 — 통과/반려 판정 출력
python3 tools/report_audit.py verdict \
  --results '<작성 완료한 JSON>' \
  --report <보고서 파일명>
```

**【통과】** 전부 통과 → 보고서 게시 가능; **【반려】** 통과하지 못한 항목이 있음 → 수정 후 재심사.
