## 번역 전문

**원제:** 경영진 심층 리서치: 주식을 사는 것은 사람을 사는 것

$ARGUMENTS 에 대해 경영진 심층 리서치를 수행합니다.

**지원하는 입력 형식**: `회사명` 또는 `인명 회사명`. 예: `메이퇀`, `왕싱 메이퇀`, `젠슨 황 엔비디아`

> "주식을 사는 것은 결국 사람을 사는 것입니다. 믿을 수 있는 사람을 찾았다면 오래 함께하세요." —— 돤융핑
>
> "경영진을 평가하려면 아무도 보지 않을 때 그들이 무엇을 하는지 봐야 합니다." —— 버핏

## 설계 철학

대부분의 투자 분석은 경영진 평가가 이력, 지분율, 보상 같은 겉모습에 머뭅니다. 하지만 버핏은 많은 시간을 들여 **경영진과 식사하며 대화했고**, 리루는 **자신의 투자는 본질적으로 사람에 대한 투자**라고 말했으며, 돤융핑은 **주식을 사는 것은 사람을 사는 것**이라고 했습니다.

이 스킬은 `/investment-research` 5단계 경영진 평가의 **심화판**입니다. 표준 투자 리서치에서 경영진 점수가 불확실하거나(★★★ 이하), 경영진이 핵심 투자 논리일 때 이 스킬로 심층 리서치를 수행합니다.

AI는 경영진과 식사를 할 수는 없지만, 공개 정보를 통해 다음을 할 수 있습니다.
- **경영진의 말과 행동이 일치하는지 추적** (약속 vs 이행)
- **모든 중대한 자본 배분 결정의 수익 분석**
- **어려운 시기의 결정에서 인품을 추론**
- **직원/입점 업체/고객의 피드백으로 간접 검증**

## 실행 절차

### 1단계: 핵심 경영진을 식별하고 병렬 데이터 수집 시작

WebSearch로 다음 핵심 인물을 확인합니다.

| 역할 | 이름 | 재임 기간 | 배경 | 지분/스톡옵션 |
|------|------|------|------|----------|
| CEO/이사회 의장 | | | | |
| CFO | | | | |
| 창업자 (현직이 아닌 경우) | | | | |
| 실질 지배자 (CEO와 다른 경우) | | | | |
| 기타 핵심 임원 | | | | |

**주의**: '누가 실제로 결정을 내리는가'와 '누구의 이름이 직함에 올라 있는가'를 구분합니다. 어떤 기업은 창업자가 물러났어도 여전히 영혼 같은 인물로 남아 있습니다 (예: 핀둬둬에서의 황정).

핵심 인물을 확인한 뒤, Task 도구로 여러 백그라운드 Agent를 실행해 다음 데이터를 **병렬로** 수집합니다.
1. Agent 1: CEO의 공개 발언과 예측 기록 (주주서한, 실적 발표 콘퍼런스콜, 인터뷰, 소셜미디어)
2. Agent 2: 자본 배분 결정 기록 (인수합병, 자사주 매입, 배당, 신사업 투자)
3. Agent 3: 지배구조와 보상 (지분 구조, 특수관계자 거래, 임원 보상)
4. Agent 4: 간접 검증 정보 (직원 평가, 고객 피드백, 업계 평판)

### 2단계: CEO 능력범위 평가

#### 2.1 전략적 안목

CEO의 지난 5년간 공개 발언(주주서한, 콘퍼런스콜, 인터뷰, 소셜미디어)을 검색해, 다음 질문에 대한 판단을 추출합니다.

| 시기 | CEO의 판단/예측 | 실제 결과 | 정확도 |
|------|--------------|---------|:------:|
| | "우리는 X 시장이 ...할 것이라고 봅니다" | X 시장은 실제로... | ✅/❌ |
| | "향후 3년 우리의 중점은 ...입니다" | 실제 실행은... | ✅/❌ |

**핵심 질문**:
- CEO가 시장보다 앞서 올바른 판단을 내린 적이 있는가?
- CEO가 모두가 낙관할 때 냉정함을 유지했는가?
- CEO의 업계 추세 이해는 시장을 따라가는가, 독립적으로 사고하는가?

#### 2.2 실행 능력

| 차원 | 평가 | 증거 |
|------|------|------|
| 전략에서 실행까지 | 말한 것을 해냈는가? | |
| 조직 역량 | 인재를 끌어오고 붙잡아 둘 수 있는가? | |
| 위기 대응 | 어려움에 부딪혔을 때 어떻게 대응하는가? | |
| 반복 개선 속도 | 실수한 뒤 바로잡는 속도가 빠른가? | |

### 3단계: 정직성 평가 (가장 중요)

**버핏**: "우리는 세 가지 자질을 찾습니다. 정직함, 지성, 그리고 에너지입니다. 첫 번째가 없다면 나머지 두 가지가 오히려 당신을 망칠 것입니다."

#### 3.1 약속 vs 이행 추적

지난 3년간의 실적 발표 콘퍼런스콜, 주주서한, 공개 인터뷰에서 경영진이 했던 **구체적인 약속**을 추출합니다.

| # | 시기 | 약속 내용 | 약속한 자리 | 이행 상황 | 평가 |
|---|------|---------|---------|---------|------|
| 1 | | "2025년에 X 사업을 흑자로 전환하겠습니다" | 2024년 연간 실적 콘퍼런스콜 | | ✅/⚠️/❌ |
| 2 | | "$X억 규모의 자사주 매입을 계획하고 있습니다" | 2024년 주주서한 | | ✅/⚠️/❌ |

**이행률 통계**:

| 약속 이행률 | 평가 |
|:---------:|------|
| >80% | 우수 — 말한 것은 지킨다 |
| 60-80% | 합격 — 큰 방향은 맞지만 실행에 편차가 있다 |
| 40-60% | 우려됨 — 약속은 많고 성과는 부족하다 |
| <40% | 심각한 문제 — 신뢰할 수 없다 |

#### 3.2 어려운 시기의 모습

기업이 과거에 겪은 중대한 위기/어려움(주가 폭락, 실적 미달, 규제 충격, 경쟁 심화)을 검색하고, 경영진의 대응을 분석합니다.

| 위기 사건 | 시기 | 경영진의 반응 | 사후에 돌아본 평가 |
|---------|------|-----------|-------------|

**주목할 점**:
- 적극적으로 소통했는가, 회피했는가?
- 원인을 내부에서 찾았는가, 외부에 책임을 떠넘겼는가?
- 위기를 기회로 삼아 어렵지만 옳은 일을 했는가, 단기적으로 시장의 비위를 맞추는 쪽을 택했는가?

#### 3.3 이해관계자를 대하는 태도

| 이해관계자 | 경영진의 태도 | 증거 | 평가 |
|-----------|-----------|------|------|
| 주주 | 존중/무시/이용 | | |
| 직원 | 우대/착취/무관심 | | |
| 고객/사용자 | 고객 중심/단기적 쥐어짜기 | | |
| 입점 업체/공급업체 | 공정한 협력/극단적 가격 후려치기 | | |
| 규제 당국/사회 | 규정 준수와 협조/편법 줄타기 | | |

**리루**: "이해관계자를 대하는 태도가 기업의 장기적인 생명력을 결정합니다. 단기적인 쥐어짜기는 효율을 높일 수 있지만, 길게 보면 생태계를 해칩니다."

### 4단계: 자본 배분 능력

이것은 버핏이 가장 중시하는 경영진의 능력입니다 — **1원을 벌 때마다 경영진은 그것을 얼마로 불릴 수 있는가?**

#### 4.1 자본 배분 결정 기록

기업의 지난 5년간 중대한 자본 배분 결정을 검색해, 건별로 평가합니다.

**인수합병 기록**:

| 시기 | 인수 대상 | 금액 | 전략적 논리 | 사후 수익 | 점수(1-5) |
|------|---------|------|---------|---------|:---------:|

**자사주 매입 기록**:

`tools/financial_rigor.py verify-valuation` 으로 매입 당시와 현재의 PER 등 밸류에이션 지표를 검증합니다.

| 시기 | 매입 금액 | 평균 매입가 | 당시 PER | 사후에 돌아보면 | 점수(1-5) |
|------|---------|-----------|:------:|---------|:---------:|

**배당 기록**:

| 연도 | 배당 금액 | 배당성향 | 같은 기간 FCF | 지속 가능한가 |
|------|---------|:------:|---------|:---------:|

**신사업 투자**:

| 시기 | 투자 분야 | 누적 투입액 | 현재 상태 | 수익 평가 | 점수(1-5) |
|------|---------|---------|---------|---------|:---------:|

#### 4.2 자본 배분 점수

| 차원 | 점수(1-5) | 설명 |
|------|:---------:|------|
| 인수합병 규율 | | 합리적인 가격에 인수했는가? 인수 후 통합은 어땠는가? |
| 자사주 매입 타이밍 | | 저평가일 때 매입하고, 고평가일 때 멈췄는가? |
| 배당의 합리성 | | 배당성향이 FCF와 맞는가? |
| 신사업 투자 | | 성공률은 어떤가? 손절 규율은 어떤가? |
| 현금 관리 | | 현금 보유액이 합리적인가? 지나치게 쌓아 두지는 않는가? |
| **종합 점수** | | |

**버핏의 기준**: 이상적인 경영진은 좋은 기회가 있을 때 과감하게 투자하고, 좋은 기회가 없을 때는 적극적으로 자사주 매입/배당을 하며, 비싼 인수합병은 절대 하지 않습니다.

|------|-----------|:------------:|:---------:|:-------:|

**주목할 점**: 인센티브 구조가 장기 주주의 이익과 일치하는가? 아니면 단기적인 행동을 부추기는가?

#### 5.3 특수관계자 거래

| 특수관계자 | 거래 내용 | 금액 | 공정한가 | 리스크 평가 |

### 6단계: 간접 검증

AI는 경영진과 얼굴을 맞대고 대화할 수 없지만, 공개 채널의 간접 정보로 검증할 수 있습니다. **주의**: 아래 정보는 공개적으로 검색 가능한 내용에 달려 있어 불완전할 수 있으므로, 정보 출처와 입수 가능성을 표시합니다.

#### 6.3 업계 평판

업계 포럼과 소셜미디어를 검색해, 동종 업계 종사자와 업계 관계자들이 해당 경영진을 어떻게 평가하는지 파악합니다.

### 7단계: CEO가 떠난 뒤의 시나리오 분석

**버핏**: "좋은 기업은 바보도 경영할 수 있어야 합니다. 언젠가는 바보가 경영하게 될 테니까요."

| 질문 | 답변 |
|------|------|
| CEO가 내일 떠난다면 회사는 정상적으로 돌아갈 수 있는가? | |
| 현재 경영진의 층은 얼마나 두터운가? 명확한 후계자가 있는가? | |
| 회사의 경쟁우위는 CEO 개인에게 달려 있는가, 조직/시스템에 달려 있는가? | |
| 과거의 경영진 교체는 순조로웠는가? | |

### 8단계: 경영진 평가 보고서 출력

#### 보고서 구조

```
1. 핵심 인물 요약 (표)
2. 정직성 평가
   - 약속 이행률
   - 어려운 시기의 모습
   - 이해관계자를 대하는 태도
3. 역량 평가
   - 전략적 안목 (예측 정확도)
   - 실행 능력
   - 자본 배분 기록
4. 지배구조
   - 지분 구조 리스크
   - 보상의 합리성
   - 특수관계자 거래
5. 간접 검증
   - 직원의 시각
   - 고객/입점 업체의 시각
6. 종합 점수와 결론
```

#### 종합 점수

| 차원 | 가중치 | 점수(1-5) | 가중 점수 |
|------|:----:|:---------:|:----:|

## 핵심 원칙

- **정직성은 즉시 탈락 항목입니다** — 능력 부족은 배워서 채울 수 있지만, 인품의 문제는 고칠 수 없습니다

- **어려움 속에서 진실을 봅니다** — 순풍일 때는 누구나 좋은 CEO이고, 역풍일 때 비로소 진짜 실력이 드러납니다
- **자본 배분은 최종 시험입니다** — 돈을 버는 것은 쉽지만, 번 돈을 잘 배분하기는 어렵습니다
