# `/thesis-tracker` · 투자 논리 추적

> 📄 원문: [skills/thesis-tracker.md](https://github.com/xbtlin/ai-berkshire/blob/main/skills/thesis-tracker.md) · 원문은 중국어이며, 아래는 한국어 번역입니다.

::: tip 한눈에 보기
- **무엇을 하나요?** 처음 쓸 때는 "왜 샀는지"를 5문장 투자 논리, 검증 가능한 핵심 가정, 매도 조건(레드라인), 밸류에이션 기준점으로 정리해 두고, 이후에는 최신 실적과 뉴스로 가정 하나하나와 레드라인을 점검해 건전성 점수를 매겨요.
- **언제 쓰나요?** 종목을 새로 사기 전이나 산 직후, 그리고 분기 실적이 나올 때마다 "아직 계속 들고 있어도 되는지" 감정이 아닌 규칙으로 판단하고 싶을 때 써요.
- **사용 예:** `/thesis-tracker 腾讯` (원문 입력 형식 기준이에요. `腾讯 建立论文`(논리 새로 수립), `腾讯 季度检查`(분기 점검)처럼 모드를 지정할 수도 있어요.)
- **결과물:** `reports/{회사명}-thesis.md` 파일에 투자 논리가 저장되고, 점검할 때마다 추적 기록 표에 한 줄씩 추가돼요.
- **핵심 특징:** 매수 전에 매도 조건을 먼저 적어 두고, 가정별 🟢🟡🔴⚫ 상태 판정, 공식으로 계산하는 10점 만점 건전성 점수, 점수에 따른 행동 제안까지 해 줘요.
:::

## 번역 전문

**원제:** 투자 논리 추적: 매수 후 규율 시스템

$ARGUMENTS 에 대해 투자 논리(thesis) 추적 점검을 수행합니다.

**지원 입력 형식**:
- `公司名`(회사명) — 처음 사용할 때는 투자 논리를 수립하고, 이후 사용할 때는 추적 점검을 합니다
- `公司名 建立论文`(회사명 논리 수립) — 투자 논리를 강제로 다시 수립합니다
- `公司名 季度检查`(회사명 분기 점검) — 최신 실적 보고서를 바탕으로 논리를 점검합니다

> "매수는 시작일 뿐입니다. 진짜 일은 보유 기간 내내 이어지는 추적입니다." —— 리루
>
> "사실이 바뀌면 나는 생각을 바꿉니다. 당신은 어떻게 하십니까?" —— 케인스

## 설계 이념

대부분의 투자자가 밟는 과정은 리서치 → 매수 → 기도입니다. 매수 후의 체계적인 추적이 없기 때문에 다음과 같은 일이 벌어집니다.
- 팔아야 할 때 아까워서 못 팝니다("조금만 더 기다리면 다시 오를 거야")
- 팔지 말아야 할 때 공포에 질려 팝니다("20%나 떨어졌어, 내가 틀린 건가")
- 처음에 왜 샀는지 잊어버립니다("내가 이걸 뭐 때문에 샀더라?")

버핏과 리루의 방식은 **매수하기 전에 매도 조건을 적어 두는 것**입니다. 그런 다음 매 분기 논리가 온전한지 점검합니다.

## 실행 절차

### 1단계: 작동 모드 판단

해당 회사의 투자 논리 파일(`reports/{회사명}-thesis.md`)이 이미 있는지 확인합니다.
- 없으면 → **논리 수립** 모드로 진입합니다
- 있으면 → **추적 점검** 모드로 진입합니다
- 찾을 수 없는데 사용자가 이미 있다고 하면 → 파일 경로를 물어봅니다

## 모드 A: 투자 논리 수립

### A0: 데이터 수집

WebSearch를 사용해 현재 주가, 밸류에이션 지표(PER/PBR/배당수익률), 최신 실적 보고서의 핵심 데이터를 확보해 밸류에이션 기준점을 채우는 데 사용합니다. 해당 회사의 `/investment-research` 또는 `/investment-team` 보고서가 이미 있으면 거기서 먼저 읽어 옵니다.

`tools/financial_rigor.py verify-valuation`을 사용해 밸류에이션 데이터를 검증합니다.

### A1: 핵심 논리(반드시 200자 이내로 명확하게 쓸 것)

투자 논리는 다음 5가지 질문에 답해야 하며, 질문마다 한 문장으로 답합니다.

```
나는 ___위안에 ___회사를 매수한다. 이유는 다음과 같다:
1. 이 사업의 본질은 ___이며, 나는 이 회사가 돈을 버는 방식을 이해한다
2. 이 회사의 해자는 ___이며, 넓어지고 있다/안정적이다
3. 경영진은 ___하며, 신뢰할 만한 이유는 ___이다
4. 현재 가격은 내재가치의 ___% 수준이며, 안전마진은 ___에서 나온다
5. 내가 틀리더라도 하방 위험은 통제 가능하다. 이유는 ___이다
```

**5문장을 온전히 써내지 못한다면 이 논리 자체에 문제가 있는 것입니다. 매수 결정이 충분히 명확하지 않다는 뜻입니다.**

### A2: 핵심 가정 목록

투자 논리를 검증 가능한 구체적인 가정으로 분해합니다.

| # | 핵심 가정 | 검증 방법 | 검증 빈도 | 현재 상태 |
|---|---------|---------|---------|---------|
| 1 | 예: 매출 성장률 15%+ 유지 | 분기보고서 매출 성장률 | 매 분기 | 🟢 유효 |
| 2 | 예: 매출총이익률 60%+ 안정 | 분기보고서 매출총이익률 | 매 분기 | 🟢 유효 |
| 3 | 예: 경영진의 지속적인 자사주 매입 | 자사주 매입 공시/현금흐름표 | 매 분기 | 🟢 유효 |
| 4 | 예: 경쟁사가 돌파구를 마련하지 못함 | 산업 데이터/경쟁사 실적 보고서 | 반기마다 | 🟢 유효 |
| 5 | ... | ... | ... | ... |

보통 3~7개의 가정을 둡니다. 너무 적으면 생각이 충분히 깊지 않다는 뜻이고, 너무 많으면 논리의 초점이 흐리다는 뜻입니다.

### A3: 레드라인 목록(어느 하나라도 발동 = 반드시 재평가)

| # | 레드라인 조건 | 심각도 | 발동 후 조치 |
|---|---------|---------|-----------|
| 1 | 예: 경영진의 신뢰성 문제(회계 부정, 특수관계자 거래) | 치명적 | 즉시 전량 매도 |
| 2 | 예: 핵심 사업의 매출이 2개 분기 연속 감소 | 심각 | 50% 비중 축소 후 재평가 |
| 3 | 예: 해자가 명백히 뚫림(경쟁사가 동등한 역량을 확보) | 심각 | 심층 리서치 착수, 퇴출 고려 |
| 4 | 예: 규제 정책이 비즈니스 모델을 근본적으로 바꿈 | 심각 | 내재가치 재평가 |
| 5 | 예: 경영진의 대규모 지분 매도(계획에 없던 것) | 경고 | 원인을 깊이 조사 |

**돤융핑**: "팔아야 할 이유는 세 가지뿐입니다. 1. 잘못 샀다는 걸 알게 됐을 때, 2. 회사의 펀더멘털이 변했을 때, 3. 더 좋은 것을 찾았을 때."

### A4: 밸류에이션 기준점

| 지표 | 매수 시점 | 낙관 목표 | 중립 목표 | 비관 시나리오 |
|------|-------|---------|---------|---------|
| 주가 | | | | |

| 시가총액 | | | | |
| 내재가치 추정 | | | | |

### A5: 논리 저장

투자 논리를 `reports/{회사명}-thesis.md`에 작성하며, 다음을 포함합니다.
- 수립 날짜
- 매수 가격과 비중
- 핵심 논리(5문장)
- 핵심 가정 목록

- 밸류에이션 기준점

## 모드 B: 추적 점검

### B1: 기존 논리 읽기

`reports/{회사명}-thesis.md`를 읽어 다음을 불러옵니다.
- 핵심 논리
- 핵심 가정 목록
- 레드라인 목록
- 직전 점검 기록

### B2: 최신 데이터 수집

WebSearch를 사용해 다음을 수집합니다.
1. 최신 실적 보고서 데이터(새 분기보고서/연차보고서가 있는 경우)
2. 최근의 중대 사건(경영진 교체, 규제 정책, 경쟁 동향)
3. 현재 주가와 밸류에이션 지표
4. 내부자 거래 기록(대주주의 지분 매수·매도)

### B3: 핵심 가정을 하나씩 점검

각 핵심 가정을 최신 데이터로 검증합니다.

| # | 핵심 가정 | 직전 상태 | 최신 증거 | 현재 상태 | 변화 |
|---|---------|---------|---------|---------|------|
| 1 | 매출 성장률 15%+ | 🟢 유효 | Q4 매출 성장률 12% | 🟡 한계적 약화 | ⚠️ |
| 2 | 매출총이익률 60%+ | 🟢 유효 | 매출총이익률 61.2% | 🟢 유효 | — |
| 3 | ... | ... | ... | ... | ... |

상태 정의:
- 🟢 **유효** — 최신 데이터가 해당 가정을 뒷받침합니다
- 🟡 **한계적 약화** — 데이터는 아직 허용 범위 안에 있지만 추세가 불리합니다
- 🔴 **훼손** — 데이터가 해당 가정을 명백히 뒷받침하지 않습니다
- ⚫ **붕괴** — 가정이 이미 뒤집혔습니다

### B4: 레드라인 점검

레드라인 목록을 하나씩 점검합니다.

| # | 레드라인 조건 | 발동 여부 | 증거 |
|---|---------|:-------:|------|
| 1 | 경영진의 신뢰성 문제 | ❌ 미발동 | — |
| 2 | 핵심 사업 2개 분기 연속 감소 | ❌ 미발동 | — |

**레드라인이 하나라도 발동되면 → 보고서에 눈에 띄게 표시하고, 명확한 행동 제안을 제시합니다.**

### B6: 추적 보고서 출력

#### 보고서 구성

```
1. 논리 건전성 점수(10점 만점)
2. 핵심 가정 점검 결과(표)
3. 레드라인 점검 결과(표)
4. 이번 기의 핵심 변화(500자 이내)
5. 밸류에이션 업데이트
6. 결론과 행동 제안
7. 다음 점검 때 주목할 사항
```

#### 논리 건전성 점수 기준

| 점수 | 의미 | 제안 조치 |
|:----:|------|---------|
**계산 공식**: 건전성 = 10 - (⚫붕괴 가정 수×3) - (🔴훼손 가정 수×2) - (🟡약화 가정 수×1) - (레드라인 발동 수×5), 최저 1점, 최고 10점.

| 점수 | 의미 | 제안 조치 |
|:----:|------|---------|
| 9-10 | 모든 가정이 유효하며, 논리가 매수 시점보다 강해짐 | 추가 매수 고려 |
| 7-8 | 핵심 가정은 유효하고, 일부만 한계적으로 약화 | 계속 보유 |
| 5-6 | 1~2개 가정이 훼손됐지만 핵심 논리는 그대로 | 보유하되 경계 강화 |
| 3-4 | 여러 가정이 훼손되어 논리의 기반이 흔들림 | 비중 축소 고려 |
| 1-2 | 레드라인 발동 또는 핵심 가정 붕괴 | 매도 강력 권고 |

#### 결론은 반드시 다음 질문에 명확히 답할 것

1. **논리가 아직 온전한가?** 온전 / 한계적 약화 / 훼손 / 붕괴
2. **어떻게 해야 하는가?** 추가 매수 / 보유 / 비중 축소 / 전량 매도
3. **다음 점검 시점**: 다음 분기보고서 발표 후 / 특정 사건 이후

### B7: 논리 파일 업데이트

이번 점검 기록을 `reports/{회사명}-thesis.md`의 추적 기록 표에 추가합니다.

| 점검 날짜 | 건전성 | 핵심 변화 | 행동 제안 |
|---------|:------:|---------|---------|
| 2026-04-09 | 7/10 | 매출 성장률이 12%로 둔화됐지만 이익률은 개선 | 보유 |

## 핵심 원칙

- **매수 전에 매도 조건을 적어 둡니다** — 냉정할 때 내린 결정이 공포에 질렸을 때 내린 결정보다 낫습니다
- **논리는 검증 가능할 만큼 구체적이어야 합니다** — "회사가 좋다"는 논리가 아닙니다. "ROE>25%이고 추세가 안정적"이어야 논리입니다
- **레드라인이 발동되면 바로 행동합니다** — 가장 무서운 것은 "좀 더 지켜보자"이며, 이것이 큰돈을 잃는 시작입니다
- **논리 붕괴 ≠ 주가 하락** — 주가가 30% 떨어졌다고 꼭 팔아야 하는 것은 아닙니다. 논리가 붕괴했을 때 팔아야 합니다
- **실수를 정직하게 마주합니다** — 논리를 잘못 세웠다면 인정하고, 체면 때문에 억지로 버티지 마세요
